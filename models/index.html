Models

NAMpy provides a comprehensive suite of interpretable and high-performance models for tabular data. Most models are available in three variants: regression, classification, and distributional regression (LSS). Some models are specialized (for example, QNAM is distributional-only, while TreeNAM and SNAM are currently regression-only).

Model Families

Additive Models (Interpretable)

These models decompose predictions into feature-level contributions:

NAM (Neural Additive Model)

The foundational interpretable model. Each feature’s contribution is modeled independently using a neural network.

\[f(x) = \beta_0 + \sum_{i=1}^{d} f_i(x_i) + \sum_{S \in \mathcal{I}} f_S(x_S)\]

Where \(f_i\) is a feature-specific MLP, and the optional interaction set \(\mathcal{I}\) is used when interaction_degree >= 2.

from nampy.models import NAMRegressor

model = NAMRegressor(
    layer_sizes=[128, 128, 32],
    numerical_preprocessing="ple"
)

GPNAM (Gaussian Process NAM)

Extends NAM with Gaussian processes for uncertainty quantification.

\[\phi(x) = \sqrt{\frac{2}{M}} \left[\cos\left(\frac{z_m x_j}{\ell} + c_{m,j}\right)\right]_{j=1..d,\,m=1..M}, \quad f(x) = \phi(x)^\top w\]

This model uses random Fourier features (RFF) with kernel width \(\ell\) and learns a linear predictor over the RFF mapping.

from nampy.models import GPNAMRegressor

model = GPNAMRegressor()

TreeNAM

Combines tree-based methods with additive modeling.

\[f(x) = \sum_{i=1}^{d} f_i(x_i), \quad f_i(x_i) = \sum_{m=1}^{M} \eta \, T_{i,m}(x_i)\]

Each feature has a boosted ensemble of neural decision trees \(T_{i,m}\) with learning rate \(\eta\).

from nampy.models import TreeNAMRegressor

model = TreeNAMRegressor()

SNAM (Sparse NAM)

Applies sparsity constraints for automatic feature selection.

\[f(x) = \beta_0 + \sum_{i=1}^{d} \sum_{k=1}^{K} w_{i,k} B_k(x_i) + \sum_{S \in \mathcal{I}} f_S(x_S)\]

Here \(B_k\) are cubic spline basis functions with learnable knots.

from nampy.models import SNAMRegressor

model = SNAMRegressor()

NodeGAM

Efficient node-based generalized additive model.

\[f(x) = \sum_{t=1}^{T} g_t(x_{S_t}), \quad |S_t| \in \{1,2\}\]

Each oblivious tree \(g_t\) selects one feature (GAM) or a pair of features (GA2M) and the outputs are summed across trees and layers.

from nampy.models import NodeGAMRegressor

model = NodeGAMRegressor()

Basis Function Models

NBM (Neural Basis Model)

Uses learned basis functions for feature transformations.

\[h(x) = \Big[B_{S,k}(x_S)\Big]_{S \in \mathcal{S},\,k=1..K}, \quad f(x) = W\,g(h(x)) + b\]

For each n-ary subset \(S\), the basis network outputs \(K\) basis responses that are combined by a grouped featurizer \(g\) and a final linear layer.

from nampy.models import NBMRegressor

model = NBMRegressor()

Attention-Based Models

NATT (Neural Attentive Tabular Transformer)

Transformer architecture with attention mechanisms.

\[f(x) = \beta_0 + \sum_{i=1}^{d_\text{num}} f_i(x_i) + g\!\left(\mathrm{Transformer}(E(x_\text{cat}))\right) + \sum_{S \in \mathcal{I}} f_S(x_S)\]

Numerical features use per-feature subnetworks, while categorical features are embedded and passed through a transformer encoder and MLP head \(g\).

from nampy.models import NATTRegressor

model = NATTRegressor()

NAMformer

Combines NAM’s interpretability with transformer architecture.

\[h = \mathrm{Transformer}(E(x)), \quad f(x) = g(h_{\text{[CLS]}}) + \sum_{i=1}^{d} f_i(e_i) + \sum_{S \in \mathcal{I}} f_S(e_S)\]

Each token embedding \(e_i\) contributes through a linear head \(f_i\), while the [CLS] token is mapped by \(g\) and summed with interactions.

from nampy.models import NAMformerRegressor

model = NAMformerRegressor()

Specialized Models

QNAM (Quantile NAM)

Designed specifically for quantile regression.

\[q_{\tau_k}(x) = \beta_0 + \sum_{i=1}^{d} f_i(x_i) + \sum_{S \in \mathcal{I}} f_S(x_S), \quad k = 1,\dots,K\]

The model outputs a set of quantile functions \(q_{\tau_k}\) for requested quantile levels \(\tau_k\).

from nampy.models import QNAM

model = QNAM()
model.fit(X, y, distributional_kwargs={"quantiles": [0.1, 0.5, 0.9]})

LinReg (Neural Linear Regression)

Neural network implementation of linear regression.

\[f(x) = \beta_0 + \sum_{i=1}^{d} w_i^\top x_i\]

Each feature is mapped by a linear layer and summed with an intercept term.

from nampy.models import LinRegRegressor

model = LinRegRegressor()

Task Variants

Most models are available in three variants:

Regression

For continuous target variables:

from nampy.models import NAMRegressor, GPNAMRegressor, NBMRegressor
# etc.

Classification

For categorical target variables:

from nampy.models import NAMClassifier, GPNAMClassifier, NBMClassifier
# etc.

Distributional Regression (LSS)

For modeling full probability distributions:

from nampy.models import NAMLSS, GPNAMLSS, NBMLSS, NodeGAMLSS
# etc.

model = NAMLSS()
model.fit(X, y, family="normal", max_epochs=150)
