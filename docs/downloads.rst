Download documentation
======================

EPUB
----

Use the Read the Docs version menu to download the EPUB for the version you
are reading.

PDF
---

The complete PDF manual is compiled and published by GitHub Actions:

1. Open the `Docs workflow <https://github.com/OpenTabular/NAMpy/actions/workflows/docs.yml>`_.
2. Select a successful run for the branch, tag, or commit you need.
3. Under **Artifacts**, download **docs-pdf** and extract ``NAMpy.pdf``.

GitHub requires you to sign in to download workflow artifacts. PDF artifacts
are retained for 90 days. Check the run's commit when matching a manual to your
installed version.

The website and EPUB are published by Read the Docs independently of PDF
compilation, so the full manual does not delay website updates.
