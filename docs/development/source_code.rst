Browse source code
==================

Browse the implementation by package. Each source page links back to its API
reference through its ``[docs]`` links. Source browsing is separate from choosing
a model or completing a task; start with :doc:`/howto/index` for those workflows.

The generated source index below includes only modules collected by Sphinx's
API documentation. The `complete repository <https://github.com/OpenTabular/NAMpy>`_
also contains examples, tests and documentation sources.
