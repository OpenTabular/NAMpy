Runtime-Checked Optimizer Routes
================================

The table is generated by fitting small representative models and checking
finite coefficients or the expected rejection. It records model type, family,
criterion, outer and coefficient solvers, and correlation structure separately.
Stopping status and warnings are reported separately from "Finite fit":
a finite coefficient vector is not a convergence claim. Missing stopping
information is labeled "Not reported". Fixed smoothing has no outer
optimization and is labeled "Not applicable". Expected rejections retain
the actual exception reason.

It is a tested sample of routes, not an exhaustive Cartesian product or a
numerical-parity claim. The dispatch code remains authoritative for a supplied
model, and upstream-reference tests cover numerical agreement separately.

.. include:: /_generated/reference/optimizer_routes.inc

Regeneration commands are in :doc:`../contributing`. The
:doc:`compatibility page <../compatibility>` explains the intentional
boundaries, including transformed likelihoods and correlated non-Gaussian
models.
