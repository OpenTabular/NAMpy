Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``dropout``
     - ``float``
     - ``0.1``
     - Dropout rate for regularization.
   * - ``interaction_degree``
     - ``int | None``
     - ``None``
     - Maximum order of automatically enumerated explicit source-feature interactions.
   * - ``interactions``
     - ``Sequence[tuple[str, ...]] | None``
     - ``None``
     - Explicit tuples of source-feature names; each term receives those inputs jointly.
   * - ``intercept``
     - ``bool``
     - ``True``
     - Include a trainable predictor intercept.
   * - ``feature_dropout``
     - ``float``
     - ``0.0``
     - Probability of dropping a whole term per observation, sharing the mask across output columns; disabled during evaluation.
   * - ``smoothing``
     - ``float``
     - ``0.0``
     - Coefficient of the spline roughness penalty.
   * - ``identify``
     - ``bool``
     - ``True``
     - Apply the spline-layer identification/centering convention.
   * - ``learn_knots``
     - ``bool``
     - ``False``
     - Allow spline knot locations to be learned rather than fixed.
   * - ``n_knots``
     - ``int``
     - ``12``
     - Number of knots in each learnable spline feature layer; basis width follows the spline construction, not a hidden MLP width.
