NAMformer API
=============

:doc:`Model structure, interpretation and restrictions </models/namformer>`.

Feature-specific marginal heads plus named interactions and an all-feature global_transformer term.

Constructor defaults and parameter descriptions below are resolved from the installed estimator and its architecture configuration. Each supported task has its own reference page.
