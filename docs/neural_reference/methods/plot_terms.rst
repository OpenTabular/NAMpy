plot_terms
==========

Numeric single-column term curves; interaction effects use plot_interactions.

Signature
---------

.. code-block:: python

   estimator.plot_terms(self, X, *, center=False, reference_X=None, reference_weight=None, rug=None, density=True, density_bins=30, density_color='#D73027', pages=0, figsize=None)

Parameters
----------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / shape
     - Default
     - Meaning
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d)``
     - Required
     - Prediction/training feature matrix with n rows and the same d columns, names and preprocessing schema used by the fitted estimator.
   * - ``center``
     - ``bool``
     - ``False``
     - Center displayed link-scale contributions against reference_X (or X when omitted), transferring their means to the intercept while preserving predictions.
   * - ``reference_X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n_ref, d) | None``
     - ``None``
     - Reference population for contribution centering. It must have the same feature schema as X; None uses X.
   * - ``reference_weight``
     - ``array-like, shape (n_ref,) | None``
     - ``None``
     - Optional reference-population weights used for centering; one value per reference_X row.
   * - ``rug``
     - ``bool | None``
     - ``None``
     - Include observed values as rug marks; None uses the renderer default.
   * - ``density``
     - ``bool``
     - ``True``
     - Draw a distribution/density display below supported feature-effect panels.
   * - ``density_bins``
     - ``int``
     - ``30``
     - Positive number of bins in the marginal feature distribution display.
   * - ``density_color``
     - ``str``
     - ``'#D73027'``
     - Matplotlib color for the marginal density display.
   * - ``pages``
     - ``int``
     - ``0``
     - Panel pagination: zero uses the renderer default; positive values select the requested panel-page layout.
   * - ``figsize``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional Matplotlib (width, height) in inches.
