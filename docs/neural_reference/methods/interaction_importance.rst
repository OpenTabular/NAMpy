interaction_importance
======================

Interaction-only subset of the term-importance table; an empty table is valid without interactions.

Signature
---------

.. code-block:: python

   estimator.interaction_importance(self, X, *, center: 'bool' = False, reference_X=None, reference_weight=None)

Parameters
----------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / shape
     - Default
     - Meaning
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d)``
     - Required
     - Prediction/training feature matrix with n rows and the same d columns, names and preprocessing schema used by the fitted estimator.
   * - ``center``
     - ``bool``
     - ``False``
     - Center displayed link-scale contributions against reference_X (or X when omitted), transferring their means to the intercept while preserving predictions.
   * - ``reference_X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n_ref, d) | None``
     - ``None``
     - Reference population for contribution centering. It must have the same feature schema as X; None uses X.
   * - ``reference_weight``
     - ``array-like, shape (n_ref,) | None``
     - ``None``
     - Optional reference-population weights used for centering; one value per reference_X row.

     - Shape

   * - pandas.DataFrame
     - (n_interaction_outputs, 4)
     - Interaction-only subset of the term-importance table; an empty table is valid without interactions.
