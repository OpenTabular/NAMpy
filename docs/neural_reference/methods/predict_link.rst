predict_link
============

Additive predictors in ``predictor_names_`` order, including aligned known offsets.

Signature
---------

.. code-block:: python

   estimator.predict_link(self, X, *, batch_size=None, offset=None)

Parameters
----------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / shape
     - Default
     - Meaning
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d)``
     - Required
     - Prediction/training feature matrix with n rows and the same d columns, names and preprocessing schema used by the fitted estimator.
   * - ``batch_size``
     - ``int | None``
     - ``None``
     - Positive prediction minibatch size; None uses the estimator/data-module default. It changes memory use, not the output dimensions.
   * - ``offset``
     - ``float | array-like, shape (n,) or (n, q) | None``
     - ``None``
     - Known additive predictor offsets with shape (n,K); a vector is accepted only for K=1. No scalar or predictor broadcasting.

Returns
-------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Type
     - Shape
     - Meaning
   * - numpy.ndarray
     - (n, K)
     - Additive predictors in ``predictor_names_`` order, including aligned known offsets.
