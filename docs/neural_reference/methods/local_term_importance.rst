local_term_importance
=====================

Architecture-specific polynomial term expansions for the requested output and top-k budget. Implemented by SPAM; unsupported architectures raise NotImplementedError.

Signature
---------

.. code-block:: python

   estimator.local_term_importance(self, X, *, target: 'int' = 0, top_k: 'int' = 10, batch_size: 'int | None' = None)

Parameters
----------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / shape
     - Default
     - Meaning
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d)``
     - Required
     - Prediction/training feature matrix with n rows and the same d columns, names and preprocessing schema used by the fitted estimator.
   * - ``target``
     - ``int``
     - ``0``
     - Zero-based model output index to expand; scalar regression uses zero.
   * - ``top_k``
     - ``int``
     - ``10``
     - Positive maximum number of polynomial terms retained per observation.
   * - ``batch_size``
     - ``int | None``
     - ``None``
     - Positive prediction minibatch size; None uses the estimator/data-module default. It changes memory use, not the output dimensions.
