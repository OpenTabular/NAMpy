Architecture configuration
--------------------------

Configuration class: ``DefaultGPNAMConfig``. Defaults below are resolved from its factory.

Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``lr``
     - ``float``
     - ``0.01``
     - Learning rate for the optimizer.
   * - ``lr_patience``
     - ``int``
     - ``10``
     - Number of epochs with no improvement after which learning rate will be reduced.
   * - ``weight_decay``
     - ``float``
     - ``0.0``
     - Weight decay (L2 penalty) for the optimizer.
   * - ``lr_factor``
     - ``float``
     - ``0.1``
     - Factor by which the learning rate will be reduced.
   * - ``lr_schedule``
     - ``str``
     - ``'inverse_sqrt'``
     - Learning-rate schedule used by gradient training; see the shared training contract.
   * - ``kernel_width``
     - ``float | Literal['auto']``
     - ``'auto'``
     - Kernel length scale; auto follows the fitted-input scale rule described in the GPNAM guide.
   * - ``kernel_widths``
     - ``Mapping[str, float] | None``
     - ``None``
     - Optional feature-wise kernel length scales, overriding the common width.
   * - ``rff_num_feat``
     - ``int``
     - ``100``
     - Number of random Fourier features used to approximate each kernel block.
   * - ``rff_scheme``
     - ``str``
     - ``'quasi_random'``
     - Sampling scheme used to construct random Fourier features.
   * - ``rff_random_state``
     - ``int | None``
     - ``None``
     - Random seed for Fourier frequency and phase construction.
   * - ``intercept``
     - ``bool``
     - ``True``
     - Include a trainable predictor intercept.
   * - ``solver``
     - ``str``
     - ``'cg'``
     - Architecture-native solver choice; cg uses a regularized fixed-design solve for supported GPNAM regression.
   * - ``ridge``
     - ``float``
     - ``0.05``
     - Nonnegative ridge penalty in the fixed linear-design solve.
   * - ``cg_rtol``
     - ``float``
     - ``1e-06``
     - Relative convergence tolerance for the conjugate-gradient solver.
   * - ``cg_max_iter``
     - ``int | None``
     - ``None``
     - Maximum conjugate-gradient iterations; None uses the solver default.
   * - ``interaction_degree``
     - ``int | None``
     - ``None``
     - Maximum order of automatically enumerated explicit source-feature interactions.
   * - ``interactions``
     - ``Sequence[tuple[str, ...]] | None``
     - ``None``
     - Explicit tuples of source-feature names; each term receives those inputs jointly.
