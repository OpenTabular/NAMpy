SemiStructured API
==================

:doc:`Model structure, interpretation and restrictions </models/semistructured>`.

Joint fixed-penalty structured effects and a learned global neural representation, residualized against all structured columns on training rows. New-data predictions use the saved training projection. See :doc:`/user_guide/semistructured` for the scalar-response, categorical-input and classification scope.

Constructor defaults and parameter descriptions below are resolved from the installed estimator and its architecture configuration. Each supported task has its own reference page.

Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``structured_formula``
     - ``str | None``
     - ``None``
     - Right-hand-side statistical formula for the structured block on preprocessed training features; None selects all numeric linear effects.
   * - ``neural_features``
     - ``tuple[str, ...]``
     - ``()``
     - Distinct numeric source features supplied jointly to the learned representation; empty selects all.
   * - ``hidden_dims``
     - ``tuple[int, ...]``
     - ``(16,)``
     - Hidden widths of the learned Tanh representation; empty selects a linear representation.
   * - ``representation_dim``
     - ``int``
     - ``8``
     - Number of learned neural representation columns before projection.
   * - ``k``
     - ``int``
     - ``6``
     - Default structured smooth basis dimension, overridden by explicit formula terms.
   * - ``basis``
     - ``str``
     - ``'tp'``
     - Default structured smooth basis type, overridden by explicit formula terms.
