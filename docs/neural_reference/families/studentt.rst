studentt
========

.. math::

   f(y)=\frac{\Gamma((\nu+1)/2)}{\Gamma(\nu/2)\sqrt{\nu\pi}\,\sigma}\left(1+\frac{(y-\mu)^2}{\nu\sigma^2}\right)^{-(\nu+1)/2}

* **Natural domains:** :math:`\nu>0,\quad\mu\in\mathbb R,\quad\sigma>0`; :math:`\mu` is location and :math:`\sigma` is t scale.
* **Conditional mean:** :math:`\mathbb E[Y\mid x]=\mu` for :math:`\nu>1`; undefined otherwise.
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=\sigma^2\nu/(\nu-2)` for :math:`\nu>2`; infinite for :math:`1<\nu\leq2`; undefined for :math:`\nu\leq1`.

:math:`Y=\mu+\sigma T_\nu,\quad T_\nu\sim t_\nu`

References: `PyTorch probability distributions <https://docs.pytorch.org/docs/stable/distributions.html>`_. NAMpy defines its family transforms and point outputs below.

A Student-t location-scale model replaces Gaussian quadratic tail
growth with a logarithmic residual term. It can accommodate occasional
large residuals while retaining a smooth location predictor.

.. math::

   -\ell=\log\sigma+\frac{\nu+1}{2}\log\left(1+\frac{(y-\mu)^2}{\nu\sigma^2}\right)+c(\nu).

Degrees of freedom nu control tail thickness; the Gaussian limit
is nu tending to infinity. Sigma is a t scale, with response variance
sigma**2*nu/(nu-2) when nu>2. Finite-variance student_lss fixes nu>2;
scat and the neural Student-t interface have their own documented
estimation/domain rules. Robustness to residual outliers does not
automatically protect against influential covariate configurations.

Neural training composes this response objective with the chosen architecture. Its raw outputs pass through the configured domain transforms; likelihood parameterization and network architecture are separate choices.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Targets, transforms and scoring
-------------------------------

Target shape/encoding: ``(n,) floating scalar response; support follows the distribution definition above``. Network rows must align with target rows. Parameter column order is given in the output contract below. Positive default transforms use ``softplus(raw)+eps``; identity leaves unrestricted locations unchanged. Constructor transform options accept registered transform names or callables and must preserve the stated parameter domains.

``compute_loss`` and ``compute_loss_per_sample`` consume raw network outputs, not already transformed parameters. The scalar loss is averaged over observations. Lower loss is better. LSS scoring follows the shared estimator contract; response SD summarizes conditional variability, not estimation uncertainty. Distribution-specific moments that do not exist cannot be interpreted as finite uncertainty estimates.

Implementation definitions: :mod:`nampy.neural.families`. See the source link on the runtime contract for the implemented transforms and objective.

Neural distribution family for ``family='studentt'``. Configure its constructor through ``distributional_kwargs`` on an LSS estimator.

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``name``
     - ``str``
     - ``'StudentT'``
     - Display label for this distribution; does not change its mathematical family.
   * - ``df_transform``
     - ``str | callable(torch.Tensor) -> torch.Tensor``
     - ``'positive'``
     - Positive transform of degrees of freedom before adding min_df.
   * - ``loc_transform``
     - ``str | callable(torch.Tensor) -> torch.Tensor``
     - ``'none'``
     - Transform of the location column. For LogNormal this is the mean of log(Y), not the response mean.
   * - ``scale_transform``
     - ``str | callable(torch.Tensor) -> torch.Tensor``
     - ``'positive'``
     - Transform of the positive scale column; default positive means softplus(raw)+eps.
   * - ``min_df``
     - ``float``
     - ``0.001``
     - Positive lower offset for Student-t degrees of freedom. Mean requires df>1 and variance requires df>2.
   * - ``eps``
     - ``float``
     - ``1e-08``
     - Positive numerical floor used by positivity transforms and stable logarithms; it is not response noise.

     - torch.Tensor[floating]
     - (n,)
     - One loss contribution per observation.
   * - predict_point(raw)
     - torch.Tensor
     - (n,)
     - Family-defined floating point prediction; see the conditional mean/point contract above.
   * - predict_spread(raw)
     - torch.Tensor[floating]
     - (n,)

``forward(raw)`` transforms a tensor of network outputs into natural parameters. ``compute_loss(raw, y)`` returns the scalar training objective; ``compute_loss_per_sample(raw, y)`` retains the observation dimension. ``predict_point(raw, transformed=False)`` returns point predictions; set transformed=True only when passing already transformed values.

``predict`` returns the family point summary; ``predict_parameters`` returns natural parameter columns and ``predict_link`` returns additive predictors. Quantile-loss families return fitted quantiles and have no natural parameter matrix. Shapes and column meanings follow this family’s contract above. ``predict_point`` reduces to the family-defined point functional. Conditional spread is distributional spread, not parameter-estimation uncertainty.
