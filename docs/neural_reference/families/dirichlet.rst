dirichlet
=========

.. math::

   f(y)=\frac{\Gamma(A)}{\prod_j\Gamma(\alpha_j)}\prod_jy_j^{\alpha_j-1},\quad A=\sum_j\alpha_j

* **Natural domains:** :math:`\alpha_j>0,\quad j=1,\ldots,D`
* **Conditional mean:** :math:`\mathbb E[Y_j\mid x]=\alpha_j/A`
* **Conditional variance:** :math:`\operatorname{Var}(Y_j\mid x)=\frac{\alpha_j(A-\alpha_j)}{A^2(A+1)}`; :math:`\operatorname{Cov}(Y_i,Y_j\mid x)=-\frac{\alpha_i\alpha_j}{A^2(A+1)},\quad i\ne j`

:math:`y_j>0,\quad\sum_jy_j=1`

References: `PyTorch probability distributions <https://docs.pytorch.org/docs/stable/distributions.html>`_. NAMpy defines its family transforms and point outputs below.

A Dirichlet response is a vector of positive fractions summing to
one. Shape parameters can be split into a composition m and total
concentration A, exposing the location/concentration tradeoff.

.. math::

   A=\sum_j\alpha_j,\quad m_j=\alpha_j/A,\qquad \operatorname{Var}(Y_j)=\frac{m_j(1-m_j)}{A+1}.

Increasing all alpha values proportionally leaves the mean
composition unchanged and reduces variability. Components have
negative conditional covariance because the row sum is fixed.
This is a distribution over compositions, not a categorical
observation or unconstrained multi-output Gaussian response. Zeros
lie on the boundary and require the documented numerical handling
or a model specifically designed for boundary mass.

Neural training composes this response objective with the chosen architecture. Its raw outputs pass through the configured domain transforms; likelihood parameterization and network architecture are separate choices.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Targets, transforms and scoring
-------------------------------

Target shape/encoding: ``(n,D) floating, positive rows summing to one``. Network rows must align with target rows. Parameter column order is given in the output contract below. Positive default transforms use ``softplus(raw)+eps``; identity leaves unrestricted locations unchanged. Constructor transform options accept registered transform names or callables and must preserve the stated parameter domains.

``compute_loss`` and ``compute_loss_per_sample`` consume raw network outputs, not already transformed parameters. The scalar loss is averaged over observations. Lower loss is better. LSS scoring follows the shared estimator contract; response SD summarizes conditional variability, not estimation uncertainty. Distribution-specific moments that do not exist cannot be interpreted as finite uncertainty estimates.

Implementation definitions: :mod:`nampy.neural.families`. See the source link on the runtime contract for the implemented transforms and objective.

Neural distribution family for ``family='dirichlet'``. Configure its constructor through ``distributional_kwargs`` on an LSS estimator.

Signature

   DirichletDistribution(n_dim: Optional[int] = None, name: str = 'Dirichlet', concentration_transform: Union[str, Callable] = 'positive', target_eps: float = 1e-08, eps: float = 1e-08)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``n_dim``
     - ``int | None``
     - ``None``
     - Response dimension D, positive integer; None is inferred from the two-dimensional training target.
   * - ``name``
     - ``str``
     - ``'Dirichlet'``
     - Display label for this distribution; does not change its mathematical family.
   * - ``concentration_transform``
     - ``str | callable(torch.Tensor) -> torch.Tensor``
     - ``'positive'``
     - Transform applied to every positive Dirichlet concentration alpha_i.
   * - ``target_eps``
     - ``float``
     - ``1e-08``
     - Positive clipping margin for targets at support boundaries. Clipping changes the evaluated boundary target.
   * - ``eps``
     - ``float``
     - ``1e-08``
     - Positive numerical floor used by positivity transforms and stable logarithms; it is not response noise.

     - torch.Tensor[floating]

     - Transformed parameters in param_names order. dtype/device follow the supplied tensor.
   * - compute_loss(raw, y)
     - torch.Tensor[floating]
     - ()
     - Scalar batch training objective, averaged over rows.
   * - compute_loss_per_sample(raw, y)
     - torch.Tensor[floating]
     - (n,)
     - One loss contribution per observation.
   * - predict_point(raw)
     - torch.Tensor
     - (n, D)
     - Family-defined floating point prediction; see the conditional mean/point contract above.
   * - predict_spread
     - not a scalar spread API
     - not applicable
     - This family retains the base hook, which raises NotImplementedError. For quantile models, gaps between requested quantiles are separate interval summaries, not a predict_spread return value.

``forward(raw)`` transforms a tensor of network outputs into natural parameters. ``compute_loss(raw, y)`` returns the scalar training objective; ``compute_loss_per_sample(raw, y)`` retains the observation dimension. ``predict_point(raw, transformed=False)`` returns point predictions; set transformed=True only when passing already transformed values.

``predict`` returns family-transformed values; ``predict(raw=True)`` returns network predictors. Shapes and column meanings follow this family’s contract above. ``predict_point`` reduces to the family-defined point functional. Conditional spread is distributional spread, not parameter-estimation uncertainty.
