lognormal_observation
=====================

.. math::

   f_T(y)=\frac{f(y)}{Z}\mathbf1(L<y<U),\quad Z=F(U)-F(L)

* **Natural domains:** Log-response location :math:`\mu\in\mathbb R` and scale :math:`\sigma>0`.; fixed truncation satisfies 0<=L<U; infinite upper bounds are supported.
* **Conditional mean:** :math:`E_T[Y]=\frac{1}{Z}\int_L^U y f(y)\,dy`; the estimator's default point summary is the conditional median. This integral defines the mean mathematically; generic conditional mean evaluation is unsupported.
* **Conditional variance:** :math:`\operatorname{Var}_T(Y)=\frac{1}{Z}\int_L^U y^2 f(y)\,dy-E_T[Y]^2`; generic conditional variance evaluation is unsupported.

latent law: :math:`\log Y\sim\mathcal N(\mu,\sigma^2),\quad Y>0`. Exact observations contribute log density; censored intervals contribute log interval probability, each minus log Z

References: `PyTorch probability distributions <https://docs.pytorch.org/docs/stable/distributions.html>`_. NAMpy defines its family transforms and point outputs below.

Explicit observation targets compose lognormal log-location and log standard deviation with exact, left/right-censored and interval observations and optional fixed truncation. The natural parameters describe the latent law.

.. math::

   Z=F(U)-F(L),\quad\ell=\log f(y)-\log Z\text{ (exact)},\quad\ell=\log\{F(b)-F(a)\}-\log Z\text{ (censored)}.

Truncation conditions the prediction law; censoring records which interval was observed. ObservationTarget is separate from weights and predictors. Statistical likelihood derivatives through order four support fixed and validated Newton/BFGS REML fitting; neural losses are differentiable. The default point summary is the conditional median. Generic conditional means and variances are unsupported for these laws. Variable truncation bounds and discrete/mixed compositions are unsupported.

Neural training composes this response objective with the chosen architecture. Its raw outputs pass through the configured domain transforms; likelihood parameterization and network architecture are separate choices.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Targets, transforms and scoring
-------------------------------

Target shape/encoding: ``(n,) floating scalar response; support follows the distribution definition above``. Network rows must align with target rows. Parameter column order is given in the output contract below. Positive default transforms use ``softplus(raw)+eps``; identity leaves unrestricted locations unchanged. Constructor transform options accept registered transform names or callables and must preserve the stated parameter domains.

``compute_loss`` and ``compute_loss_per_sample`` consume raw network outputs, not already transformed parameters. The scalar loss is averaged over observations. Lower loss is better. LSS scoring follows the shared estimator contract; response SD summarizes conditional variability, not estimation uncertainty. Distribution-specific moments that do not exist cannot be interpreted as finite uncertainty estimates.

Implementation definitions: :mod:`nampy.neural.families`. See the source link on the runtime contract for the implemented transforms and objective.

Neural distribution family for ``family='lognormal_observation'``. Configure its constructor through ``distributional_kwargs`` on an LSS estimator.
