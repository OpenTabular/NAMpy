Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``n_hid``
     - ``int``
     - ``10``
     - Number of random hidden units in each extreme-learning-machine stage.
   * - ``n_estimators``
     - ``int``
     - ``5000``
     - Maximum number of stages in the architecture-native boosting fit.
   * - ``elm_scale``
     - ``float``
     - ``1.0``
     - Scale of fixed random extreme-learning-machine hidden weights.
   * - ``activation``
     - ``str | torch.nn.Module | type[torch.nn.Module]``
     - ``'elu'``
     - Activation class for the basis MLP layers (e.g. nn.ReLU); a new instance is used per layer.
   * - ``elm_random_state``
     - ``int``
     - ``0``
     - Seed for the fixed random extreme-learning-machine features.
