NBMSPAM API
===========

:doc:`Model structure, interpretation and restrictions </models/nbm_spam>`.

Constructor defaults and parameter descriptions below are resolved from the installed estimator and its architecture configuration. Each supported task has its own reference page.

Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``layer_sizes``
     - ``Sequence[int]``
     - ``[256, 128, 128]``
     - Sizes of the layers in the basis MLP.
   * - ``activation``
     - ``str | torch.nn.Module | type[torch.nn.Module]``
     - ``torch.nn.modules.activation.ReLU``
     - Activation class for the basis MLP layers (e.g. nn.ReLU); a new instance is used per layer.
   * - ``dropout``
     - ``float``
     - ``0.0``
     - Dropout rate for regularization.
   * - ``bases_dropout``
     - ``float``
     - ``0.0``
     - Dropout rate for entire basis function outputs.
   * - ``norm``
     - ``str | None``
     - ``None``
     - Normalization method (e.g. BatchNorm, LayerNorm, RMSNorm, GroupNorm).
   * - ``use_glu``
     - ``bool``
     - ``False``
     - Whether to use Gated Linear Units (GLU) in the basis MLP.
   * - ``skip_connections``
     - ``bool``
     - ``False``
     - Whether to use skip connections in the basis MLP.
   * - ``num_subnets``
     - ``int``
     - ``1``
     - Number of sub-networks to learn basis functions.
   * - ``batch_norm``
     - ``bool``
     - ``True``
     - Whether to use batch normalization in the basis MLP layers.
   * - ``layer_norm``
     - ``bool``
     - ``False``
     - Whether to use layer normalization in the basis MLP layers.
   * - ``num_bases``
     - ``int``
     - ``100``
     - Number of shared basis functions.
   * - ``featurizer``
     - ``str``
     - ``'conv1d'``
     - Per-term combination of shared basis responses. Grouped ``conv1d`` matches the released dense implementation.
   * - ``output_penalty``
     - ``float``
     - ``0.0``
     - Coefficient for L2 penalty on term scores (added to task loss when > 0).
   * - ``ranks``
     - ``Sequence[int]``
     - ``[100]``
     - Low-rank widths by polynomial head; in SPAM ranks[i] corresponds to degree i+2.
   * - ``spam_dropout``
     - ``float``
     - ``0.0``
     - Dropout probability in the polynomial heads.
   * - ``reg_order``
     - ``int``
     - ``2``
     - Norm order used by the polynomial regularization penalty; it is not polynomial degree.
   * - ``lower_order_correction``
     - ``bool``
     - ``False``
     - Remove lower-order contributions from polynomial products.
   * - ``orthogonal``
     - ``bool``
     - ``False``
     - Constrain polynomial projection matrices with an orthogonal parameterization.
   * - ``proximal``
     - ``bool``
     - ``False``
     - Use the architecture-supported proximal regularization update.
   * - ``regularization_scale``
     - ``float``
     - ``0.0``
     - Multiplier of the polynomial model parameter regularizer.
   * - ``basis_l1_regularization``
     - ``float``
     - ``0.0``
     - L1 penalty strength on learned basis/projection coefficients.
