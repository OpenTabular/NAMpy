Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``lr``
     - ``float``
     - ``0.001``
     - Learning rate for the optimizer.
   * - ``lr_patience``
     - ``int``
     - ``10``
     - Number of epochs with no improvement after which learning rate will be reduced.
   * - ``weight_decay``
     - ``float``
     - ``1e-06``
     - Weight decay (L2 penalty) for the optimizer.
   * - ``lr_factor``
     - ``float``
     - ``0.1``
     - Factor by which the learning rate will be reduced.
   * - ``tree_depth``
     - ``int``
     - ``4``
     - Number of binary decision levels in each soft tree.
   * - ``tree_lamda``
     - ``float``
     - ``0.001``
     - Coefficient of the soft-tree split regularization penalty.
   * - ``tree_temperature``
     - ``float``
     - ``1.0``
     - Controls the softness of tree routing during training.
   * - ``use_hard_routing_in_eval``
     - ``bool``
     - ``False``
     - Replace soft branch probabilities with discrete routing during evaluation.
   * - ``feature_dropout``
     - ``float``
     - ``0.0``
     - Dropout probability applied to contribution outputs; masking semantics depend on architecture.
   * - ``interaction_degree``
     - ``int | None``
     - ``None``
     - Maximum order of automatically enumerated explicit source-feature interactions.
   * - ``interactions``
     - ``Sequence[tuple[str, ...]] | None``
     - ``None``
     - Explicit tuples of source-feature names; each term receives those inputs jointly.
   * - ``intercept``
     - ``bool``
     - ``True``
     - Include a trainable predictor intercept.
   * - ``num_estimators``
     - ``int``
     - ``5``
     - Number of jointly trained additive-tree members.
   * - ``aggregation``
     - ``str``
     - ``'mean'``
     - How outputs of the configured members or terms are combined.
