Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``lr``
     - ``float``
     - ``0.0001``
     - Learning rate for the optimizer.
   * - ``lr_patience``
     - ``int``
     - ``10``
     - Number of epochs with no validation improvement before reducing the learning rate.
   * - ``weight_decay``
     - ``float``
     - ``1e-06``
     - Weight decay (L2 penalty) for the optimizer.
   * - ``lr_factor``
     - ``float``
     - ``0.1``
     - Multiplicative factor used by the learning-rate scheduler.
   * - ``layer_sizes``
     - ``Sequence[int]``
     - ``[128, 128, 32]``
     - Hidden-layer widths for each feature subnet.
   * - ``activation``
     - ``str | torch.nn.Module | type[torch.nn.Module]``
     - ``torch.nn.modules.activation.ReLU``
     - Activation class used in the hidden layers.
   * - ``dropout``
     - ``float``
     - ``0.1``
     - Dropout rate inside each feature subnet.
   * - ``norm``
     - ``str | None``
     - ``None``
     - Optional normalization layer name. Valid values depend on `components.mlp.make_norm`, e.g. "BatchNorm", "LayerNorm", "RMSNorm", "LearnableLayerScaling".
   * - ``use_glu``
     - ``bool``
     - ``False``
     - Whether to use GLU in hidden layers. If True, all hidden sizes must be even.
   * - ``skip_connections``
     - ``bool``
     - ``False``
     - Whether to use residual connections when layer dimensions match.
   * - ``batch_norm``
     - ``bool``
     - ``False``
     - Convenience flag for batch normalization. Mutually exclusive with `norm` and `layer_norm` in the cleaned-up MLP utilities.
   * - ``layer_norm``
     - ``bool``
     - ``False``
     - Convenience flag for layer normalization. Mutually exclusive with `norm` and `batch_norm` in the cleaned-up MLP utilities.
   * - ``intercept``
     - ``bool``
     - ``True``
     - Whether to include a learnable monotone intercept across quantiles.
   * - ``feature_dropout``
     - ``float``
     - ``0.0``
     - Dropout probability applied at the whole-feature contribution level.
   * - ``interaction_degree``
     - ``int | None``
     - ``None``
     - Maximum interaction degree. If None or < 2, only main effects are used. If 2, pairwise interactions are included, etc.
   * - ``interactions``
     - ``Sequence[tuple[str, ...]] | None``
     - ``None``
     - Explicit tuples of source-feature names; each term receives those inputs jointly.
   * - ``monotone_transform``
     - ``str``
     - ``'softplus'``
     - Transformation function to enforce monotonicity. Options: "softplus", "exponential".
   * - ``min_increment``
     - ``float``
     - ``0.0``
     - Minimum increment for the monotone transform. Only used if `monotone_transform` is "softplus".
