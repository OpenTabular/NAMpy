estimator_family
================

Construct the supported estimator-class family for a registered neural architecture.

Signature
---------

.. code-block:: python

   estimator_family(architecture: 'str', *, module_name: 'str', mixin: 'type | None' = None) -> 'NeuralEstimatorFamily'

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``architecture``
     - ``str``
     - Required
     - Registered neural architecture name whose supported task classes should be constructed.
   * - ``module_name``
     - ``str``
     - Required
     - Module name assigned to generated estimator classes for public imports and serialization.
   * - ``mixin``
     - ``type | None``
     - ``None``
     - Optional estimator-layer methods shared by the generated task adapters.

Returns and fitted outputs
--------------------------

Returns a NeuralEstimatorFamily record containing task-specific estimator classes or None for unavailable tasks. This record contains no fitted predictions. Instantiate one of its available classes and call fit to obtain a model.
