NeuralRegressor
===============

Construct a regression estimator around a custom architecture and configuration.

Signature
---------

.. code-block:: python

   NeuralRegressor(model, config_class, *, architecture_config=None, objective=None, training=None, preprocessing=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``model``
     - ``type[torch.nn.Module]``
     - Required
     - Custom PyTorch architecture class implementing the additive forward-output contract; see the custom-model guide.
   * - ``config_class``
     - ``type``
     - Required
     - Architecture configuration class used by a generic estimator.
   * - ``architecture_config``
     - ``architecture configuration dataclass | None``
     - ``None``
     - Architecture configuration instance; representation controls have no flat overrides.
   * - ``objective``
     - ``ObjectiveConfig | None``
     - ``None``
     - ObjectiveConfig containing task-specific loss or distribution family settings.
   * - ``training``
     - ``GradientTrainingConfig | FixedDesignTrainingConfig | NativeTrainingConfig | None``
     - ``None``
     - Route-specific gradient, fixed-design or architecture-native training record; None resolves the supported default.
   * - ``preprocessing``
     - ``PreprocessingConfig | None``
     - ``None``
     - PreprocessingConfig containing feature transformation choices.

Returns and fitted outputs
--------------------------

Construction returns an unfitted estimator and fit returns self. NeuralRegressor.predict returns response predictions; NeuralClassifier.predict returns labels and predict_proba returns class probabilities. NeuralLSS.predict returns transformed distribution parameters and predict(raw=True) returns the network predictors. Additive components describe the link scale under the architecture's declared dependence contract.
