NeuralClassifier
================

Construct a classification estimator around a custom architecture and configuration.

Signature
---------

.. code-block:: python

   NeuralClassifier(model, config, **kwargs)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``model``
     - ``type[torch.nn.Module]``
     - Required
     - Custom PyTorch architecture class implementing the additive forward-output contract; see the custom-model guide.
   * - ``config``
     - ``type[dataclass configuration]``
     - Required
     - Configuration class (for example DefaultNAMConfig, without parentheses). The estimator instantiates it using configuration overrides; passing an already constructed instance raises TypeError.
   * - ``kwargs``
     - ``keyword arguments``
     - Variable arguments
     - Preprocessing and estimator configuration overrides accepted by the custom estimator. Architecture-specific controls come from its config.

Returns and fitted outputs
--------------------------

Construction returns an unfitted estimator and fit returns self. NeuralRegressor.predict returns response predictions; NeuralClassifier.predict returns labels and predict_proba returns class probabilities. NeuralLSS.predict returns transformed distribution parameters and predict(raw=True) returns the network predictors. Additive components describe the link scale under the architecture's declared dependence contract.
