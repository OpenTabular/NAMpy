NeuralEstimatorFamily
=====================

Record the available regression, classification and distributional estimator classes for an architecture.

Signature
---------

.. code-block:: python

   NeuralEstimatorFamily(regressor: 'type | None' = None, classifier: 'type | None' = None, lss: 'type | None' = None) -> None

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``regressor``
     - ``type | None``
     - ``None``
     - Optional estimator class for regression; None means that task is unavailable.
   * - ``classifier``
     - ``type | None``
     - ``None``
     - Optional estimator class for classification; None means that task is unavailable.
   * - ``lss``
     - ``type | None``
     - ``None``
     - Optional distributional estimator class; None means that task is unavailable.

Returns and fitted outputs
--------------------------

Returns a NeuralEstimatorFamily record containing task-specific estimator classes or None for unavailable tasks. This record contains no fitted predictions. Instantiate one of its available classes and call fit to obtain a model.
