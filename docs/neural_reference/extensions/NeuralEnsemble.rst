NeuralEnsemble
==============

Fit independent replicas of a neural regressor or classifier, each owning its preprocessing and fitted state.

Signature
---------

.. code-block:: python

   NeuralEnsemble(estimator, n_estimators: 'int' = 5, random_state: 'int' = 101, n_jobs: 'int | None' = 1, bootstrap: 'bool' = False)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``estimator``
     - ``unfitted neural regressor or classifier``
     - Required
     - Unfitted neural regressor/classifier template; each ensemble member receives an independent sklearn clone. LSS aggregation is unsupported.
   * - ``n_estimators``
     - ``int``
     - ``5``
     - Positive number of independently fitted ensemble members; default five.
   * - ``random_state``
     - ``int``
     - ``101``
     - Base training seed; member i uses base_seed+i through its constructor training configuration.
   * - ``n_jobs``
     - ``int | None``
     - ``1``
     - Joblib parallel worker count, default one. Each worker trains its own member.
   * - ``bootstrap``
     - ``bool``
     - ``False``
     - Whether to resample training rows with replacement independently per member. Supplied row weights and offsets are resampled with the same indices.

Returns and fitted outputs
--------------------------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Operation
     - Result
   * - ``fit``
     - Fits the members and exposes them in ``estimators_``. Accepts explicit validation data, offsets and weights, and returns the ensemble.
   * - ``predict``
     - Mean member response for regression or most probable class for classification.
   * - ``predict_proba``
     - Mean member probabilities in ``classes_`` order.
   * - ``predict_components``
     - Mean link-scale contributions as ``AdditivePrediction``.
   * - ``predict_component_uncertainty``
     - Mean contributions and between-member variation as ``EnsembleAdditivePrediction``. Missing selected terms contribute zero for that member.
   * - ``score``
     - R² for regression and accuracy for classification.

Between-member variation describes training or selection variability. Calibrated confidence intervals require a separate inference method.
