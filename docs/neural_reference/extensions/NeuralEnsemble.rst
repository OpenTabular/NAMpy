NeuralEnsemble
==============

Fit independent replicas of a neural regressor or classifier, each owning its preprocessing and fitted state.

Signature
---------

.. code-block:: python

   NeuralEnsemble(estimator, n_estimators: 'int' = 5, random_state: 'int' = 101, n_jobs: 'int | None' = 1, bootstrap: 'bool' = False)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``estimator``
     - ``unfitted neural regressor or classifier``
     - Required
     - Unfitted neural regressor/classifier template; each ensemble member receives an independent sklearn clone. LSS aggregation is unsupported.
   * - ``n_estimators``
     - ``int``
     - ``5``
     - Positive number of independently fitted ensemble members; default five.
   * - ``random_state``
     - ``int``
     - ``101``
     - Base training seed. Member i uses base_seed+i; fit-time random_state overrides this value.
   * - ``n_jobs``
     - ``int | None``
     - ``1``
     - Joblib parallel worker count, default one. Each worker trains its own member.
   * - ``bootstrap``
     - ``bool``
     - ``False``
     - Whether to resample training rows with replacement independently per member. Supplied row weights and offsets are resampled with the same indices.

Returns and fitted outputs
--------------------------

Construction returns an unfitted ensemble; ``fit(X, y, **fit_params)`` returns self and exposes ``estimators_``. Regression predict returns the mean member response, shaped like a member's predictions. Classification predict_proba averages probabilities in ``classes_`` order, and predict returns the most probable class. score returns R² or accuracy, respectively. ``predict_components`` returns ``AdditivePrediction`` containing the mean link-scale contributions. ``predict_component_uncertainty`` returns ``EnsembleAdditivePrediction`` containing mean components and between-member variation; missing selected terms contribute zero for that member. Variation across members measures training/selection variability and is not automatically a calibrated confidence interval.
