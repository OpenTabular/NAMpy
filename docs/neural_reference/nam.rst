Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``lr``
     - ``float``
     - ``0.0001``
     - Learning rate for the optimizer.
   * - ``lr_patience``
     - ``int``
     - ``10``
     - Number of epochs with no improvement after which learning rate will be reduced.
   * - ``weight_decay``
     - ``float``
     - ``1e-06``
     - Weight decay (L2 penalty) for the optimizer.
   * - ``lr_factor``
     - ``float``
     - ``0.1``
     - Factor by which the learning rate will be reduced.
   * - ``layer_sizes``
     - ``Sequence[int]``
     - ``[128, 128, 32]``
     - Sizes of the layers in the MLP.
   * - ``feature_layer``
     - ``str``
     - ``'linear'``
     - Parameterized first-layer type for each feature network: ``"linear"``, ``"exu"``, or ``"centered_relu"``.
   * - ``activation``
     - ``str | torch.nn.Module | type[torch.nn.Module]``
     - ``torch.nn.modules.activation.ReLU``
     - Conventional pointwise activation used by linear hidden layers.
   * - ``dropout``
     - ``float``
     - ``0.1``
     - Dropout rate for regularization.
   * - ``norm``
     - ``str | None``
     - ``None``
     - Normalization method to be used, if any.
   * - ``use_glu``
     - ``bool``
     - ``False``
     - Whether to use Gated Linear Units (GLU) in the MLP.
   * - ``skip_connections``
     - ``bool``
     - ``False``
     - Whether to use skip connections in the MLP.
   * - ``batch_norm``
     - ``bool``
     - ``False``
     - Whether to use batch normalization in the MLP layers.
   * - ``layer_norm``
     - ``bool``
     - ``False``
     - Whether to use layer normalization in the MLP layers.
   * - ``interaction_degree``
     - ``int | None``
     - ``None``
     - Maximum order of automatically enumerated explicit source-feature interactions.
   * - ``interactions``
     - ``Sequence[tuple[str, ...]] | None``
     - ``None``
     - Explicit tuples of source-feature names; each term receives those inputs jointly.
   * - ``intercept``
     - ``bool``
     - ``True``
     - Include a trainable predictor intercept.
   * - ``feature_dropout``
     - ``float``
     - ``0.0``
     - Dropout probability applied to contribution outputs; masking semantics depend on architecture.
   * - ``adaptive_width``
     - ``bool``
     - ``False``
     - Derive each main-effect first-layer width from its transformed training cardinality. Disabled by default.
   * - ``num_basis_functions``
     - ``int``
     - ``1000``
     - Positive upper bound on the first-layer width when NAM adaptive_width is enabled.
   * - ``units_multiplier``
     - ``int``
     - ``2``
     - Positive multiplier of fitted feature cardinality in adaptive first-layer width selection.
   * - ``feature_widths``
     - ``Mapping[str, int]``
     - ``{}``
     - Explicit positive first-layer widths indexed by source-feature name; override adaptive width selection.
   * - ``feature_output_bias``
     - ``bool``
     - ``True``
     - Whether a feature head includes its own output bias.
   * - ``output_regularization``
     - ``float``
     - ``0.0``
     - Mean-squared feature-contribution penalty coefficient.
   * - ``l2_regularization``
     - ``float``
     - ``0.0``
     - Explicit normalized parameter L2 penalty coefficient, separate from optimizer weight decay.
   * - ``regularize_interactions``
     - ``bool``
     - ``False``
     - Apply the NAM output/parameter regularizers to interaction subnetworks as well as main effects.
