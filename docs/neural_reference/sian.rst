Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``lr``
     - ``float``
     - ``0.005``
     - Learning rate for the optimizer.
   * - ``lr_patience``
     - ``int``
     - ``10``
     - Number of epochs with no improvement after which learning rate will be reduced.
   * - ``weight_decay``
     - ``float``
     - ``0.0``
     - Weight decay (L2 penalty) for the optimizer.
   * - ``lr_factor``

     - ``str``

   * - ``optimizer``

   * - ``layer_sizes``

     - ``[16, 12, 8]``

   * - ``activation``
     - ``str | torch.nn.Module | type[torch.nn.Module]``
     - ``torch.nn.modules.activation.ReLU``

   * - ``intercept``
     - ``bool``
     - ``True``
     - Include a trainable predictor intercept.
   * - ``feature_output_bias``
     - ``bool``
     - ``True``
     - Whether a feature head includes its own output bias.
   * - ``l1_regularization``
     - ``float``
     - ``5e-05``
     - Coefficient of the architecture L1 parameter penalty.
   * - ``execution_mode``
     - ``str``
     - ``'block_masked'``
     - SIAN execution layout, including block-masked versus independent subnetworks.
   * - ``residual_network``
     - ``bool``
     - ``False``
     - Include the optional SIAN residual network.
   * - ``residual_layer_sizes``
     - ``Sequence[int]``
     - ``[256, 128, 64]``
     - Hidden widths of the optional SIAN residual reference network.
   * - ``interaction_detector``
     - ``str``
     - ``'archipelago'``
     - SIAN candidate-selection method; explicit interactions bypass discovery.
   * - ``max_interaction_order``
     - ``int``
     - ``3``
     - Highest interaction order considered by SIAN discovery.
   * - ``interaction_thresholds``
     - ``float | Mapping[int, float]``
     - ``0.1``
     - Interaction acceptance threshold, globally or indexed by order.
   * - ``threshold_mode``
     - ``str``
     - ``'fraction'``
     - Interpret interaction thresholds as relative fractions or according to the configured detector policy.
   * - ``heredity_fraction``
     - ``float``
     - ``0.5``
     - SIAN heredity filter for admitting higher-order interaction candidates.
   * - ``max_candidates``
     - ``int``
     - ``1000``
     - Maximum number of interaction candidates considered during discovery.
   * - ``max_terms_per_order``
     - ``int | Mapping[int, int] | None``
     - ``None``
     - Optional cap on accepted interaction terms at each order.
   * - ``archipelago_baseline``
     - ``str``
     - ``'pairwise'``
     - Reference configuration used to score Archipelago interaction candidates.
   * - ``selection_max_samples``
     - ``int``
     - ``128``
     - Maximum observations used during interaction selection.
   * - ``selection_max_pairs``
     - ``int``
     - ``1024``
     - Maximum sample-pair budget used for interaction scoring.
   * - ``selection_batch_size``
     - ``int``
     - ``1024``
     - Batch size when scoring candidate interactions.
   * - ``selection_output_index``
     - ``int``
     - ``0``
     - Output dimension examined by the interaction detector.
   * - ``reference_layer_sizes``
     - ``Sequence[int]``
     - ``[256, 128, 64]``
     - Hidden widths of the interaction-detector reference network.
   * - ``reference_epochs``
     - ``int``
     - ``100``

   * - ``reference_batch_size``
     - ``int``
     - ``128``

   * - ``reference_weight_decay``
