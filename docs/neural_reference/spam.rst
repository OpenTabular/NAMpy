SPAM API
========

:doc:`Model structure, interpretation and restrictions </models/spam>`.

Low-rank polynomial blocks; interpret their configured feature subsets, not independent unary networks.

Constructor defaults and parameter descriptions below are resolved from the installed estimator and its architecture configuration. Each supported task has its own reference page.

Architecture configuration
--------------------------

Configuration class: ``DefaultSPAMConfig``. Defaults below are resolved from its factory.

Configuration parameters
------------------------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``lr``
     - ``float``
     - ``0.001``
     - Learning rate for the optimizer.
   * - ``lr_patience``
     - ``int``
     - ``10``
     - Number of epochs with no improvement after which learning rate will be reduced.
   * - ``weight_decay``
     - ``float``
     - ``0.0``
     - Weight decay (L2 penalty) for the optimizer.
   * - ``lr_factor``
     - ``float``
     - ``0.1``
     - Factor by which the learning rate will be reduced.
   * - ``ranks``
     - ``Sequence[int]``
     - ``[100]``
     - Low-rank widths by polynomial head; in SPAM ranks[i] corresponds to degree i+2.
   * - ``dropout``
     - ``float``
     - ``0.0``
     - Dropout rate for regularization.
   * - ``ignore_unary``
     - ``bool``
     - ``False``
     - Omit the direct unary block from the polynomial representation.
   * - ``reg_order``
     - ``int``
     - ``2``
     - Norm order used by the polynomial regularization penalty; it is not polynomial degree.
   * - ``lower_order_correction``
     - ``bool``
     - ``False``
     - Remove lower-order contributions from polynomial products.
   * - ``use_geometric_mean``
     - ``bool``
     - ``True``
     - Normalize polynomial products using the configured geometric-mean representation.
   * - ``orthogonal``
     - ``bool``
     - ``False``
     - Constrain polynomial projection matrices with an orthogonal parameterization.
   * - ``proximal``
     - ``bool``
     - ``False``
     - Use the architecture-supported proximal regularization update.
   * - ``regularization_scale``
     - ``float``
     - ``0.0``
     - Multiplier of the polynomial model parameter regularizer.
   * - ``basis_l1_regularization``
     - ``float``
     - ``0.0``
     - L1 penalty strength on learned basis/projection coefficients.
   * - ``intercept``
     - ``bool``
     - ``True``
     - Include a trainable predictor intercept.
