gam_vcomp
=========

Express smoothing penalties as variance components.

Signature
---------

.. code-block:: python

   GAM.gam_vcomp(self, *, rescale=True, conf_lev=0.95)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``rescale``
     - ``bool``
     - ``True``
     - Undo internal penalty rescaling when expressing variance components in the original penalty units.
   * - ``conf_lev``
     - ``float``
     - ``0.95``
     - Confidence level in (0, 1) for available variance-component intervals.

Returns
-------

A mapping of variance-component standard deviations and names, with confidence limits where available; None for unsupported/absent penalty configurations.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - vc
     - numpy.ndarray[float64]
     - (n_penalties,) or (n_free [+ scale], 3)
     - Standard deviations alone, or columns SD/lower/upper when supported intervals are available.
   * - names
     - str | list[str]
     - aligned with vc rows
     - Component labels.
   * - all / all_names
     - array-like / list[str] | None
     - full mapped component order
     - Expanded linked-penalty components, where applicable.
   * - rank / rank_hess / conf_lev
     - int / int / float | None
     - scalar
     - Available curvature rank and interval coverage. Entire result is None when components cannot be reported.
