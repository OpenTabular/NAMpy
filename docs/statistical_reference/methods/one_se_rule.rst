one_se_rule
===========

Choose smoother penalty strengths using the fitted criterion uncertainty.

Signature
---------

.. code-block:: python

   GAM.one_se_rule(self, candidate_indices=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``candidate_indices``
     - ``Sequence[int] | None``
     - ``None``
     - Optional indices of smoothing parameters considered by the one-standard-error selection rule.

Returns
-------

NumPy smoothing-parameter vector suggested by the one-standard-error rule. Inspect/refit explicitly before using it for predictions.

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - smoothing
     - numpy.ndarray[float64]
     - (n_penalties,)
     - Candidate smoothing strengths; the model is not automatically refitted.
