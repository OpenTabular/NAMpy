concurvity
==========

Measure overlap between smooth design spaces.

Signature
---------

.. code-block:: python

   GAM.concurvity(self, full=True)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``full``
     - ``bool``
     - ``True``
     - Whether to compare each term with all remaining terms jointly, rather than compute pairwise concurvity.

Returns
-------

Full or pairwise concurvity arrays/dictionaries as defined by the diagnostics backend. Values near one indicate greater representability by other terms, which can destabilize effect attribution.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - measure_names
     - tuple[str, str, str]
     - length 3
     - worst, observed, estimate.
   * - labels
     - list[str]
     - length t
     - Design-space/term labels.
   * - values (full=True)
     - numpy.ndarray[float64]
     - (3, t)
     - Each term compared with the remaining design jointly.
   * - values (full=False)
     - dict[str, numpy.ndarray]
     - 3 arrays, each (t, t)
     - Pairwise matrices indexed by measure name.
