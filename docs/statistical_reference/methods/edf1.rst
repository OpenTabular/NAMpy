edf1
====

Report an upper-bound effective degrees of freedom per coefficient.

Signature
---------

.. code-block:: python

   GAM.edf1(self) -> numpy.ndarray

Parameters
----------

No additional parameters.

Returns
-------

NumPy vector of length n_coefficients, computed as 2*diag(F) - rowSums(F*F').

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - edf
     - numpy.ndarray[float64]
     - (p,)
     - Per-coefficient upper-bound EDF, in coefficient order.
