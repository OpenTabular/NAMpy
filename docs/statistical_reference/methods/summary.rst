summary
=======

Summarize coefficients, smooth terms, effective degrees of freedom and fit quality.

Signature
---------

.. code-block:: python

   GAM.summary(self, *, dispersion=None, freq=False, re_test=True)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``dispersion``
     - ``float | None``
     - ``None``
     - Optional dispersion override used to rescale uncertainty and tests; None uses the fitted scale.
   * - ``freq``
     - ``bool``
     - ``False``
     - Use frequentist coefficient covariance rather than the default Bayesian penalized covariance.
   * - ``re_test``
     - ``bool``
     - ``True``
     - Include supported random-effect term tests in the summary.

Returns
-------

GAMSummary structured record; also prints the formatted summary. Smooth significance tests are approximate and condition on the fitted smoothing treatment.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - summary
     - GAMSummary
     - scalar record
     - Contains parametric and smooth significance tables, EDF, dispersion and goodness-of-fit fields; the method also prints the summary.

The :ref:`quadratic-form inference explanation <quadratic-form-inference>` describes weighted chi-square reference laws, numerical tail evaluation and approximation limits.
