lpmatrix
========

Build a design matrix in the fitted coefficient coordinates for new observations.

Signature
---------

.. code-block:: python

   GAM.lpmatrix(self, X, *, block_size=None, newdata_guaranteed=False, na_action='pass')

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d)``
     - Required
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``block_size``
     - ``int | None``
     - ``None``
     - Optional row-block size for prediction to limit intermediate matrix memory.
   * - ``newdata_guaranteed``
     - ``bool``
     - ``False``
     - Skip supported new-data checks after validating the optimized prediction contract; requires complete explicit new data.
   * - ``na_action``
     - ``str``
     - ``'pass'``
     - Missing-data policy: pass restores missing rows as NaN; omit/exclude retain complete rows; fail rejects missing prediction inputs.

Returns
-------

Dense NumPy matrix with n_samples rows and n_coefficients columns. Multiplying by coefficients reconstructs the linear predictor excluding known offsets.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - matrix
     - numpy.ndarray[float64]
     - (n, p)
     - Design in fitted coefficient coordinates, excluding offsets.
