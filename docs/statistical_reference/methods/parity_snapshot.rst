parity_snapshot
===============

Capture fitted quantities for numerical reference comparisons.

Signature
---------

.. code-block:: python

   GAM.parity_snapshot(self, X=None, include_covariances=False)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d) | None``
     - ``None``
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``include_covariances``
     - ``bool``
     - ``False``
     - Include potentially large coefficient covariance arrays in the returned fit record/snapshot.

Returns
-------

Serializable snapshot mapping with coefficient/prediction/penalty summaries and optional covariances.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - snapshot
     - dict[str, object]
     - named fitted payload
     - Serializable coefficients, penalties, predictions, metadata and optionally covariance arrays; see the concrete example schema below.
