predict_terms
=============

Extract named term predictions from the fitted model.

Signature
---------

.. code-block:: python

   GAM.predict_terms(self, X=None, offset=None, *, block_size=None, newdata_guaranteed=False, na_action='pass')

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d) | None``
     - ``None``
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``offset``
     - ``float | array-like, shape (n,) or (n, q) | None``
     - ``None``
     - Known additive predictor offset, scalar/vector or supported per-predictor structure. New data require the appropriate new-data offset.
   * - ``block_size``
     - ``int | None``
     - ``None``
     - Optional row-block size for prediction to limit intermediate matrix memory.
   * - ``newdata_guaranteed``
     - ``bool``
     - ``False``
     - Skip supported new-data checks after validating the optimized prediction contract; requires complete explicit new data.
   * - ``na_action``
     - ``str``
     - ``'pass'``
     - Missing-data policy: pass restores missing rows as NaN; omit/exclude retain complete rows; fail rejects missing prediction inputs.

Returns
-------

A dictionary with output (full link predictor), named term arrays and intercept/offset entries; non-Gaussian families also include response. Multi-predictor term keys include eta indices. Contributions add on the link scale.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - output
     - numpy.ndarray
     - (n,) or (n, q)
     - Complete additive link predictor.
   * - term label keys
     - numpy.ndarray
     - (n,)
     - One vector per term/predictor label. Multi-predictor keys carry eta indices.
   * - intercept
     - numpy.ndarray (scalar) | dict[str, float]
     - scalar(s)
     - Predictor intercept(s).
   * - offset
     - numpy.ndarray | dict | None
     - (n,) or per-predictor arrays
     - Known offsets, when present.
   * - response
     - numpy.ndarray
     - family-specific
     - Included for non-Gaussian families.
