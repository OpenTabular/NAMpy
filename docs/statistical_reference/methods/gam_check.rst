gam_check
=========

Prepare numerical convergence, residual and basis-dimension checks.

Signature
---------

.. code-block:: python

   GAM.gam_check(self, *, type='deviance', k_sample=5000, k_rep=200, seed=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``type``
     - ``str``
     - ``'deviance'``
     - Prediction mode: response, link, terms, iterms or lpmatrix. Response applies the family transformation; link retains additive predictors; term modes return contributions; lpmatrix returns the coefficient design.
   * - ``k_sample``
     - ``int``
     - ``5000``
     - Maximum rows used in the basis-dimension portion of gam_check.
   * - ``k_rep``
     - ``int``
     - ``200``
     - Number of residual permutations in the basis-dimension portion of gam_check.
   * - ``seed``
     - ``int | None``
     - ``None``
     - Optional random seed for permutations or simulated diagnostic reference data.

Returns
-------

Structured diagnostic report including supported residual and k-check results. Use plot_check for figures.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - report
     - dict[str, object]
     - named diagnostic fields
     - Numerical convergence/residual report plus basis-dimension checks. The example below lists the actual returned fields.

For raw outer-gradient, Hessian and boundary diagnostics, see :doc:`optimizer_endpoint_diagnostics </extension_reference/statistical/optimizer_endpoint_diagnostics>`. Coefficient convergence and smoothing-endpoint stationarity are separate checks.
