qq
==

Plot upstream-style residual QQ data with optional simulated envelopes.

Signature
---------

.. code-block:: python

   GAM.qq(self, *, rep=0, level=0.9, s_rep=10, type='deviance', seed=None, quantile_permutations=None, response_draws=None, figsize=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``rep``
     - ``int``
     - ``0``
     - Number of simulated response replicates for a QQ reference envelope; zero uses the analytic reference route.
   * - ``level``
     - ``float``
     - ``0.9``
     - Pointwise interval/envelope coverage probability, between zero and one.
   * - ``s_rep``
     - ``int``
     - ``10``
     - Reference-quantile replication count for QQ construction.
   * - ``type``
     - ``str``
     - ``'deviance'``
     - Prediction mode: response, link, terms, iterms or lpmatrix. Response applies the family transformation; link retains additive predictors; term modes return contributions; lpmatrix returns the coefficient design.
   * - ``seed``
     - ``int | None``
     - ``None``
     - Optional random seed for permutations or simulated diagnostic reference data.
   * - ``quantile_permutations``
     - ``array-like, shape (s_rep, n) | None``
     - ``None``
     - Optional zero-based observation permutations with shape (s_rep, n), used only in the analytic reference branch rep=0. Cannot be combined with positive rep or response_draws.
   * - ``response_draws``
     - ``array-like, shape (rep, n) | None``
     - ``None``
     - Optional floating response draws with shape (rep, n), requiring rep>0. Cannot be supplied in the rep=0 quantile-permutation branch.
   * - ``figsize``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional Matplotlib figure size in inches, as (width, height).

Returns
-------

Prepared plotting data with Matplotlib figures, or figure collections as described below. Prediction values and intervals retain their documented link/response scale.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - prepared
     - dict[str, object]
     - one payload per plot or diagnostic
     - Numerical grids/effects and associated Matplotlib figures; the example schema below identifies each payload field and its concrete shape.
