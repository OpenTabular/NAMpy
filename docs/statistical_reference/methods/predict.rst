predict
=======

Predict responses, additive predictors, individual terms or a linear-predictor matrix.

Signature
---------

.. code-block:: python

   GAM.predict(self, X=None, return_se=False, cov=None, type='response', offset=None, terms=None, exclude=None, block_size=None, newdata_guaranteed=False, na_action='pass', unconditional=False, iterms_type=1)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d) | None``
     - ``None``
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``return_se``
     - ``bool``
     - ``False``
     - If True, return prediction and associated pointwise standard-error arrays as a pair.
   * - ``cov``
     - ``str | numpy.ndarray, shape (p, p) | None``
     - ``None``
     - Optional coefficient covariance selection/override. Cannot be combined with unconditional=True.
   * - ``type``
     - ``str``
     - ``'response'``
     - Prediction mode: response, link, terms, iterms or lpmatrix. Response applies the family transformation; link retains additive predictors; term modes return contributions; lpmatrix returns the coefficient design.
   * - ``offset``
     - ``float | array-like, shape (n,) or (n, q) | None``
     - ``None``
     - Known additive predictor offset, scalar/vector or supported per-predictor structure. New data require the appropriate new-data offset.
   * - ``terms``
     - ``Iterable[str] | None``
     - ``None``
     - Optional iterable of fitted term labels to include in prediction.
   * - ``exclude``
     - ``Iterable[str] | None``
     - ``None``
     - Optional iterable of fitted term labels to omit from prediction.
   * - ``block_size``
     - ``int | None``
     - ``None``
     - Optional row-block size for prediction to limit intermediate matrix memory.
   * - ``newdata_guaranteed``
     - ``bool``
     - ``False``
     - Skip supported new-data checks after validating the optimized prediction contract; requires complete explicit new data.
   * - ``na_action``
     - ``str``
     - ``'pass'``
     - Missing-data policy: pass restores missing rows as NaN; omit/exclude retain complete rows; fail rejects missing prediction inputs.
   * - ``unconditional``
     - ``bool``
     - ``False``
     - Request coefficient covariance adjusted for smoothing-parameter uncertainty when the fitted route supplies it.
   * - ``iterms_type``
     - ``int``
     - ``1``
     - Controls inclusion of mean/intercept uncertainty in iterms standard errors.

Returns
-------

A NumPy array. Scalar response/link predictions have n_samples rows; term predictions have one column per returned term; lpmatrix has one column per coefficient. General-family response predictions have family-specific widths and scales. With return_se=True, returns (prediction, standard_error). Standard errors are pointwise, not simultaneous intervals.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - prediction
     - numpy.ndarray
     - (n,) / (n, q) / (n, t) / (n, p)
     - Shape depends on type and family: response/link, terms/iterms, or lpmatrix. Multi-predictor source response columns are family-specific.
   * - standard_error
     - numpy.ndarray
     - same shape as prediction
     - Returned only as (prediction, standard_error) when return_se=True and the requested prediction route supports standard errors.
