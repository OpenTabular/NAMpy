k_check
=======

Check whether residual structure suggests an insufficient basis dimension.

Signature
---------

.. code-block:: python

   GAM.k_check(self, subsample=5000, n_rep=400, seed=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``subsample``
     - ``int``
     - ``5000``
     - Maximum rows sampled for the basis-dimension diagnostic.
   * - ``n_rep``
     - ``int``
     - ``400``
     - Number of residual permutations used to calibrate the basis-dimension diagnostic.
   * - ``seed``
     - ``int | None``
     - ``None``
     - Optional random seed for permutations or simulated diagnostic reference data.

Returns
-------

Diagnostic table containing basis dimension, EDF, k-index and permutation p-values where defined. A small p-value motivates checking a larger-k refit; it is not an automatic model rejection.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - table
     - pandas.DataFrame | None
     - (n_smooths, 4)
     - Columns k_prime, edf, k_index, p_value. None when there are no smooth terms; unsupported diagnostics may be NaN.
