save_model
==========

Serialize the fitted GAM and its family state.

Signature
---------

.. code-block:: python

   GAM.save_model(self, path)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``path``
     - ``str | pathlib.Path``
     - Required
     - Filesystem destination/source for a serialized model. Load only trusted pickle-based artifacts.

Returns
-------

Writes the model artifact at path. Solver workspace is excluded from serialization.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - return
     - pathlib.Path
     - scalar path object
     - Destination path after writing the requested model artifact; use load_model to restore it.
