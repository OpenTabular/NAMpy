anova
=====

Report within-model term tests or compare fitted models.

Signature
---------

.. code-block:: python

   GAM.anova(self, *models, dispersion=None, test=None, freq=False)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``models``
     - ``GAM positional arguments``
     - Variable arguments
     - Additional fitted models to compare; without them, report within-model term tests.
   * - ``dispersion``
     - ``float | None``
     - ``None``
     - Optional dispersion override used to rescale uncertainty and tests; None uses the fitted scale.
   * - ``test``
     - ``str | None``
     - ``None``
     - Optional model-comparison test selection, subject to family and scale support.
   * - ``freq``
     - ``bool``
     - ``False``
     - Use frequentist coefficient covariance rather than the default Bayesian penalized covariance.

Returns
-------

AnovaGAMSingle for a single model or AnovaGAMComparison for multiple models. Comparisons depend on family, dispersion and model nesting.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - table
     - AnovaGAMSingle | AnovaGAMComparison
     - scalar record
     - Within-model term tests or between-model comparison rows, depending on additional models.
