vis
===

Plot a conditional prediction surface, following ``mgcv::vis.gam``.

Signature
---------

.. code-block:: python

   GAM.vis(self, *, view=None, cond=None, n_grid=30, too_far=0, type='link', se=-1, lp=1, zlim=None, plot_type='persp', color='heat', col=None, contour_col=None, n_col=50, theta=30, phi=30, figsize=None, xlab=None, ylab=None, zlab=None, main=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``view``
     - ``Sequence[str], length 2 | None``
     - ``None``
     - Two source predictor names varied over the conditional prediction grid.
   * - ``cond``
     - ``Mapping[str, object] | None``
     - ``None``
     - Mapping fixing other predictors while the selected view predictors vary.
   * - ``n_grid``
     - ``int``
     - ``30``
     - Number of grid locations along each plotted predictor axis.
   * - ``too_far``
     - ``int``
     - ``0``
     - Distance threshold for masking grid points too far from observed covariate support; zero disables masking.
   * - ``type``
     - ``str``
     - ``'link'``
     - Prediction mode: response, link, terms, iterms or lpmatrix. Response applies the family transformation; link retains additive predictors; term modes return contributions; lpmatrix returns the coefficient design.
   * - ``se``
     - ``float | bool``
     - ``-1``
     - Number of standard errors for plotted uncertainty surfaces; nonpositive values suppress those surfaces in vis.
   * - ``lp``
     - ``int``
     - ``1``
     - One-based linear-predictor index for multi-predictor plotting.
   * - ``zlim``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional limits for the plotted prediction axis.
   * - ``plot_type``
     - ``str``
     - ``'persp'``
     - Surface display style, such as persp or contour.
   * - ``color``
     - ``str``
     - ``'heat'``
     - Named surface color scheme.
   * - ``col``
     - ``Matplotlib color | Sequence[color] | None``
     - ``None``
     - Optional explicit plotting color specification.
   * - ``contour_col``
     - ``Matplotlib color | None``
     - ``None``
     - Optional color for contour lines.
   * - ``n_col``
     - ``int``
     - ``50``
     - Number of colors in the surface palette.
   * - ``theta``
     - ``float``
     - ``30``
     - Horizontal viewing angle in degrees for a perspective surface.
   * - ``phi``
     - ``int``
     - ``30``
     - Vertical viewing angle in degrees for a perspective surface.
   * - ``figsize``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional Matplotlib figure size in inches, as (width, height).
   * - ``xlab``
     - ``str | None``
     - ``None``
     - Optional horizontal-axis label.
   * - ``ylab``
     - ``str | None``
     - ``None``
     - Optional second-axis label.
   * - ``zlab``
     - ``str | None``
     - ``None``
     - Optional prediction-axis label.
   * - ``main``
     - ``str | None``
     - ``None``
     - Optional figure title.

Returns
-------

Prepared plotting data with Matplotlib figures, or figure collections as described below. Prediction values and intervals retain their documented link/response scale.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - prepared
     - dict[str, object]
     - one payload per plot or diagnostic
     - Numerical grids/effects and associated Matplotlib figures; the example schema below identifies each payload field and its concrete shape.

For direct construction of a normalized prediction-grid mask, see :doc:`exclude_too_far </extension_reference/statistical/exclude_too_far>`. Its True entries indicate excluded grid nodes.
