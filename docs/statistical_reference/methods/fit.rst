fit
===

Fit a statistical additive model, compiling its formula and solving coefficients and optional smoothing parameters.

Signature
---------

.. code-block:: python

   GAM.fit(self, X=None, y=None, optimize_smoothing=None, smoothing_method=None, data=None, formula=None, offset=None, sample_weight=None, min_sp=None, knots=None, drop_intercept=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d) | None``
     - ``None``
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``y``
     - ``array-like, shape (n,) or family-specific (n, q) | None``
     - ``None``
     - Observed response array aligned row-for-row with X/data; formula mode can extract it from data.
   * - ``optimize_smoothing``
     - ``bool | None``
     - ``None``
     - Select smoothing parameters automatically; None at fit time preserves the constructor setting.
   * - ``smoothing_method``
     - ``str | None``
     - ``None``
     - Smoothing selection criterion; None at fit time preserves the configured choice.
   * - ``data``
     - ``pandas.DataFrame, n rows | None``
     - ``None``
     - DataFrame containing formula predictors and response. Use fit(data=data) to make formula-mode input explicit.
   * - ``formula``
     - ``str | Sequence[str] | Mapping[str, str] | None``
     - ``None``
     - Formula string or supported multi-predictor formula collection. A fit-time value overrides the configured formula.
   * - ``offset``
     - ``float | array-like, shape (n,) or (n, q) | None``
     - ``None``
     - Known additive predictor offset, scalar/vector or supported per-predictor structure. New data require the appropriate new-data offset.
   * - ``sample_weight``
     - ``array-like, shape (n,) | None``
     - ``None``
     - Prior observation weights aligned with response rows; family-specific likelihood weight conventions apply.
   * - ``min_sp``
     - ``float | array-like, shape (n_penalties,) | None``
     - ``None``
     - Optional lower bounds for penalty smoothing parameters.
   * - ``knots``
     - ``Mapping[str, array-like] | array-like | None``
     - ``None``
     - Optional supplied knot locations. Structure and required count depend on the basis; prediction reuses the fitted knot setup.
   * - ``drop_intercept``
     - ``bool | Sequence[bool] | None``
     - ``None``
     - Optional per-predictor intercept removal policy for formula compilation.

Returns
-------

The fitted GAM itself (self). A failed transactional fit does not replace a previously fitted session.
