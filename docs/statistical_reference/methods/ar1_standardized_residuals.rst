ar1_standardized_residuals
==========================

Whiten response residuals using the fitted known AR(1) transform.

Signature
---------

.. code-block:: python

   GAM.ar1_standardized_residuals(self)

Parameters
----------

No additional parameters.

Returns
-------

NumPy residual vector; available only after a nonzero ar1_rho fit.

   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - residual
     - numpy.ndarray[float64]
     - (n_train,)
     - Response residuals whitened by the known fitted AR(1) transform.
