sp_vcov
=======

Estimate covariance of free log smoothing parameters from the criterion Hessian.

Signature
---------

.. code-block:: python

   GAM.sp_vcov(self, edge_correct=True, reg=0.001)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``edge_correct``
     - ``bool``
     - ``True``
     - Apply available smoothing-criterion boundary correction when forming smoothing-parameter covariance.
   * - ``reg``
     - ``float``
     - ``0.001``
     - Numerical regularization for smoothing-criterion Hessian inversion.

Returns
-------

A square covariance array, or None when the required fitted curvature is unavailable. This is smoothing-parameter covariance, not coefficient covariance.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - covariance
     - numpy.ndarray[float64] | None
     - (r, r), possibly including scale
     - Covariance in free log-smoothing coordinates. None if required curvature is unavailable.
