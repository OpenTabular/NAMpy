derivative
==========

Evaluate an individual smooth's slope or curvature.

Signature
---------

.. code-block:: python

   GAM.derivative(self, X=None, smooth_number=1, deriv=1)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d) | None``
     - ``None``
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``smooth_number``
     - ``int``
     - ``1``
     - One-based smooth index, following the fitted smooth order.
   * - ``deriv``
     - ``int``
     - ``1``
     - Derivative order: 1 for slope or 2 for curvature where implemented by the selected smooth.

Returns
-------

SmoothDerivativeResult with evaluation points, predictor-scale derivative, Bayesian standard errors and term metadata. Nonlinear response links require a separate chain rule.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - derivative
     - numpy.ndarray[float64]
     - (n,)
     - Predictor-scale slope or curvature.
   * - se
     - numpy.ndarray[float64]
     - (n,)
     - Conditional pointwise Bayesian SE.
   * - derivative_matrix
     - numpy.ndarray[float64]
     - (n, p_term)
     - Derivative design in the selected term coefficient coordinates.
   * - term_label / order
     - str / int
     - scalar
     - Identity of the differentiated term and derivative order in SmoothDerivativeResult.
