fisher_information
==================

Evaluate mean model Fisher information at fitted parameters under the declared conditional likelihood.

Signature
---------

.. code-block:: python

   GAM.fisher_information(self, X=None, *, offset=None, context=None, config=None, return_diagonal=True, batch_size=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d) | None``
     - ``None``
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``offset``
     - ``float | array-like, shape (n,) or (n, q) | None``
     - ``None``
     - Known additive predictor offset, scalar/vector or supported per-predictor structure. New data require the appropriate new-data offset.
   * - ``context``
     - ``Mapping[str, array-like, shape (n,)] | None``
     - ``None``
     - Optional row-aligned likelihood context, such as grouped-binomial trial counts. Required fields are validated by the supported conditional likelihood.
   * - ``config``
     - ``FisherDiagnostics | None``
     - ``None``
     - Optional FisherDiagnostics configuration; None uses the estimator's configured diagnostics or shared defaults. Public postfit evaluation uses every supplied input row; n_inputs limits fit-time probes.
   * - ``return_diagonal``
     - ``bool``
     - ``True``
     - Retain aligned per-parameter information and sampling-error arrays when True; group summaries remain available when False.
   * - ``batch_size``
     - ``int | None``
     - ``None``
     - Positive prediction minibatch size; None uses the estimator/data-module default. It changes memory use, not the output dimensions.

Returns
-------

FisherInformationResult with optional per-coefficient diagonals, disjoint group traces and input/output sampling uncertainty. Exact information, sampled score outer products and sampled negative Hessians share mean normalization. Unsupported likelihoods and quasi-likelihood families fail explicitly; smoothing penalties are excluded.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - result
     - FisherInformationResult
     - scalar record; optional diagonal (p,)
     - Mean likelihood information in coefficient coordinates, disjoint group traces and sampling-error diagnostics. Penalties are excluded; this is not a coefficient covariance estimate.

Separate fit-time offsets must be supplied again, aligned with the evaluated rows. Formula and smooth offsets follow the existing prediction contract. ``X=None`` evaluates the fitted training rows. See :doc:`/user_guide/fisher_diagnostics` for estimator, nuisance-parameter and sampling assumptions.
