load_model
==========

Restore a statistical model artifact.

Signature
---------

.. code-block:: python

   GAM.load_model(path, device='cpu')

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``path``
     - ``str | pathlib.Path``
     - Required
     - Filesystem destination/source for a serialized model. Load only trusted pickle-based artifacts.
   * - ``device``
     - ``str``
     - ``'cpu'``
     - Device used by the architecture-native solver.

Returns
-------

The deserialized GAM instance. Artifacts use pickle and must come from a trusted source.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - model
     - GAM
     - scalar object
     - Restored fitted model; input/output schemas are retained.
