fit_result
==========

Export the fitted numerical result record.

Signature
---------

.. code-block:: python

   GAM.fit_result(self, include_covariances=True)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``include_covariances``
     - ``bool``
     - ``True``
     - Include potentially large coefficient covariance arrays in the returned fit record/snapshot.

Returns
-------

GAMFitResult presentation record containing fitted terms, coefficients and requested covariance payloads.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - result
     - GAMFitResult
     - scalar record
     - coef_full (p,), eta/mu (n_train,) or (n_train,q), smoothing_params (n_penalties,), covariance fields (p,p) when included; term_results contains one TermFitResult per term.
