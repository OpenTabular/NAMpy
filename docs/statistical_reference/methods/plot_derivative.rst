plot_derivative
===============

Plot a slope or curvature with a pointwise Bayesian band.

Signature
---------

.. code-block:: python

   GAM.plot_derivative(self, X=None, *, smooth_number=1, deriv=1, level=0.95, figsize=None, shade_col='0.8')

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``X``
     - ``pandas.DataFrame | numpy.ndarray, shape (n, d) | None``
     - ``None``
     - Feature data with n_samples rows and the fitted input columns; None uses training data when the method permits it.
   * - ``smooth_number``
     - ``int``
     - ``1``
     - One-based smooth index, following the fitted smooth order.
   * - ``deriv``
     - ``int``
     - ``1``
     - Derivative order: 1 for slope or 2 for curvature where implemented by the selected smooth.
   * - ``level``
     - ``float``
     - ``0.95``
     - Pointwise interval/envelope coverage probability, between zero and one.
   * - ``figsize``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional Matplotlib figure size in inches, as (width, height).
   * - ``shade_col``
     - ``Matplotlib color``
     - ``'0.8'``
     - Matplotlib color used to shade uncertainty bands.

Returns
-------

Prepared plotting data with Matplotlib figures, or figure collections as described below. Prediction values and intervals retain their documented link/response scale.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - figures
     - list[matplotlib.figure.Figure]
     - one entry per rendered panel
     - Matplotlib figures containing the derivative curve and pointwise band.
