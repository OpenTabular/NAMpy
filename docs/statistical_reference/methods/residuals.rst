residuals
=========

Compute family-specific residual diagnostics.

Signature
---------

.. code-block:: python

   GAM.residuals(self, type='deviance', *, setseed=None)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``type``
     - ``str``
     - ``'deviance'``
     - Residual definition: deviance, pearson, response, working or scaled. Availability and encoding depend on the fitted family; these are residuals, not prediction modes.
   * - ``setseed``
     - ``int | None``
     - ``None``
     - Optional seed for stochastic residual construction where supported.

Returns
-------

NumPy residual array aligned with training rows. Supported types and response encoding depend on the family; deviance residuals are not necessarily normally distributed.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - residual
     - numpy.ndarray[float64]
     - (n_train,)
     - Residual type selects the scale; supported kinds depend on the family.
