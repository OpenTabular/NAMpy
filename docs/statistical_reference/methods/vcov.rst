vcov
====

Extract coefficient covariance under the selected uncertainty convention.

Signature
---------

.. code-block:: python

   GAM.vcov(self, *, sandwich: bool = False, freq: bool = False, dispersion: float | None = None, unconditional: bool = False)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``sandwich``
     - ``bool``
     - ``False``
     - Request sandwich covariance for a supported family/fit; unsupported routes raise an error.
   * - ``freq``
     - ``bool``
     - ``False``
     - Use frequentist coefficient covariance rather than the default Bayesian penalized covariance.
   * - ``dispersion``
     - ``float | None``
     - ``None``
     - Optional dispersion override used to rescale uncertainty and tests; None uses the fitted scale.
   * - ``unconditional``
     - ``bool``
     - ``False``
     - Request coefficient covariance adjusted for smoothing-parameter uncertainty when the fitted route supplies it.

Returns
-------

A copied square NumPy covariance matrix in fitted coefficient coordinates. With unconditional=True, vcov uses the corrected matrix if available and otherwise the conditional Bayesian matrix. Unsupported sandwich/family combinations raise RuntimeError.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - covariance
     - numpy.ndarray[float64]
     - (p, p)
     - Selected coefficient covariance; symmetry follows fitted coefficient order.
