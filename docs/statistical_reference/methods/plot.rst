plot
====

mgcv ``plot.gam``-shaped term plots (mgcv/R/plots.r:1271-1565).

Signature
---------

.. code-block:: python

   GAM.plot(self, **kwargs)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``kwargs``
     - ``keyword arguments``
     - Variable arguments
     - Supported plotting keywords are listed in the method documentation below.

Returns
-------

Prepared plotting data with Matplotlib figures, or figure collections as described below. Prediction values and intervals retain their documented link/response scale.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Returned field
     - Type
     - Shape
     - Meaning
   * - prepared
     - dict[str, object]
     - one payload per plot or diagnostic
     - Numerical grids/effects and associated Matplotlib figures; the example schema below identifies each payload field and its concrete shape.

For direct construction of a normalized prediction-grid mask, see :doc:`exclude_too_far </extension_reference/statistical/exclude_too_far>`. Its True entries indicate excluded grid nodes.

Expanded plotting keyword arguments
-----------------------------------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Keyword
     - Type
     - Default
     - Meaning
   * - ``residuals``
     - ``bool``
     - ``False``
     - Draw weighted working partial residuals behind the fitted term curve.
   * - ``rug``
     - ``bool | None``
     - ``None``
     - Draw observed feature locations; None uses the prepared-data default.
   * - ``se``
     - ``bool | float``
     - ``True``
     - True uses the standard band convention; False suppresses bands; a positive number requests that many standard errors where supported.
   * - ``pages``
     - ``int``
     - ``0``
     - Requested figure-page count; zero uses the renderer automatic layout.
   * - ``select``
     - ``int | None``
     - ``None``
     - Optional zero-based smooth-panel index used by the Python renderer; None includes all plottable panels.
   * - ``scale``
     - ``int | float``
     - ``-1``
     - -1 uses common y-axis limits across compatible curves unless ylim is supplied; other values retain term-specific scaling behavior.
   * - ``n``
     - ``int``
     - ``100``
     - Positive number of grid locations for a univariate curve.
   * - ``n2``
     - ``int``
     - ``40``
     - Positive number of grid locations along each axis of a two-dimensional surface.
   * - ``n3``
     - ``int``
     - ``3``
     - Number of conditioning/slice locations for supported higher-dimensional displays.
   * - ``theta``
     - ``float | Sequence[float] | None``
     - ``30``
     - Horizontal perspective viewing angle in degrees.
   * - ``phi``
     - ``int``
     - ``30``
     - Vertical perspective viewing angle in degrees.
   * - ``jit``
     - ``bool``
     - ``False``
     - Jitter observed locations when constructing supported rug displays.
   * - ``xlab``
     - ``str | None``
     - ``None``
     - Optional horizontal-axis label.
   * - ``ylab``
     - ``str | None``
     - ``None``
     - Optional effect-axis label.
   * - ``main``
     - ``str | None``
     - ``None``
     - Optional panel title.
   * - ``ylim``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional (lower, upper) effect-axis limits; overrides common automatic limits.
   * - ``xlim``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional (lower, upper) covariate-axis limits.
   * - ``too_far``
     - ``float``
     - ``0.1``
     - Mask surface-grid points too far from observed covariate support; zero disables distance masking.
   * - ``shade_col``
     - ``Matplotlib color``
     - ``'0.8'``
     - Matplotlib color used to fill uncertainty bands.
   * - ``shift``
     - ``float``
     - ``0.0``
     - Additive display shift applied before trans; fitted predictions remain unchanged.
   * - ``trans``
     - ``callable | None``
     - ``None``
     - Optional numerical display transformation callable, applied after shift; None leaves the displayed scale unchanged.
   * - ``se_with_mean``
     - ``bool``
     - ``False``
     - Include available mean/intercept uncertainty in ordinary smooth bands. Shape-constrained routes retain their documented restrictions.
   * - ``unconditional``
     - ``bool``
     - ``False``
     - Request supported smoothing-parameter uncertainty corrections for plot bands.
   * - ``by_resids``
     - ``bool``
     - ``False``
     - Apply the supported by-variable convention to partial residual displays.
   * - ``scheme``
     - ``int | Sequence[int]``
     - ``0``
     - Basis-specific rendering scheme, scalar or one per smooth; the meaning depends on curve, tensor, MRF or spherical geometry.
   * - ``figsize``
     - ``tuple[float, float] | None``
     - ``None``
     - Optional Matplotlib figure size in inches, as (width, height).
