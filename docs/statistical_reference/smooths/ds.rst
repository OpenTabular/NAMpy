ds
==

Duchon spline: a low-rank isotropic smooth with derivative order and spectral weighting controlled by m.

Formula interface
-----------------

.. code-block:: python

   formula = "y ~ s(x, bs='ds')"

Formula constructors are parsed inside strings; they are not Python functions. ``k``, ``m``, ``by``, ``id``, ``sp`` and ``fx`` configure the term where supported. Formula ``id`` maps to runtime ``smoothing_id`` and ``fx`` maps to ``fixed``.

Runtime class: ``nampy.gam.smooths.univariate.ds.DuchonSplineTerm``. Shared class defaults may name another variant: pass ``basis='ds'`` when the constructor exposes ``basis``.

Outputs
-------

The constructor returns an unfitted runtime term. ``fit(X, feature_names)`` initializes its basis and penalties and returns the term. ``transform_new(X_new)`` returns a dense ``(n_samples, n_term_coefficients)`` matrix in the fitted constraint coordinates. ``penalties`` returns the term's penalty matrices, each square in those coefficient coordinates. The term contributes ``transform_new(X_new) @ coefficients`` on the additive predictor scale. Basis dimension can decrease after constraints; it is distinct from fitted EDF.
