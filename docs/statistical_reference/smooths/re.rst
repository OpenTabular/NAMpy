re
==

Random effect represented by a parametric indicator/product design and a ridge-type precision penalty; suitable for penalized group coefficients.

Formula interface
-----------------

.. code-block:: python

   formula = "y ~ s(x, bs='re')"

Formula constructors are parsed inside strings; they are not Python functions. ``k``, ``m``, ``by``, ``id``, ``sp`` and ``fx`` configure the term where supported. Formula ``id`` maps to runtime ``smoothing_id`` and ``fx`` maps to ``fixed``.

---------

   RandomEffectTerm(feature, label=None, term_id=None, smoothing_id=None, by=None, sp=None, select=False, xt=None, metadata=None, k=-1, fixed=False, constraint_mode='auto', knots=None)

Runtime class: ``nampy.gam.smooths.categorical.re.RandomEffectTerm``. Shared class defaults may name another variant: pass ``basis='re'`` when the constructor exposes ``basis``.

Outputs
-------

The constructor returns an unfitted runtime term. ``fit(X, feature_names)`` initializes its basis and penalties and returns the term. ``transform_new(X_new)`` returns a dense ``(n_samples, n_term_coefficients)`` matrix in the fitted constraint coordinates. ``penalties`` returns the term's penalty matrices, each square in those coefficient coordinates. The term contributes ``transform_new(X_new) @ coefficients`` on the additive predictor scale. Basis dimension can decrease after constraints; it is distinct from fitted EDF.

Implementation notes
--------------------

Random-effect smooth term (``bs='re'``).

Implements the :class:`BaseSmoothTerm` interface for a random-effect / variance
component term.  The design matrix is a dummy-coded indicator matrix for the
grouping factor, and the penalty is a scaled identity matrix (i.i.d. random
effects prior).

The smoothing parameter controls the random-effects variance: large lambda
corresponds to a tight prior (small variance, strong shrinkage toward zero).
