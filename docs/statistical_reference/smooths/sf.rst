Soap boundary film (``sf``)
===========================

Soap boundary-film component. Its values are determined by the supplied domain boundary rather than an unconstrained plane-wide spline.

Formula interface
-----------------

.. code-block:: python

   formula = "y ~ s(x, z, bs='sf')"

Formula constructors are parsed inside strings; they are not Python functions. ``k``, ``m``, ``by``, ``id``, ``sp`` and ``fx`` configure the term where supported. Formula ``id`` maps to runtime ``smoothing_id`` and ``fx`` maps to ``fixed``.

----------

   :class: api-reference-table

   * - Formula option
     - Type / shape

   * - ``by``
     - str | int | None
     - None
     - Optional numeric multiplier or factor defining varying-coefficient or level-specific effects. Identifiability constraints depend on its type.
   * - ``fx``
     - bool
     - False
     - Fit as an unpenalized regression term rather than estimating a roughness penalty (formula spelling: fx).
   * - ``id``
     - str | int | None
     - None
     - Optional identifier linking smoothing parameters across compatible terms.
   * - ``k``
     - int | Sequence[int]
     - -1
     - Boundary-film basis dimension, scalar or one value per boundary loop. It does not set the number of interior knot coefficients.
   * - ``sp``
     - float | array-like, shape (n_penalties,) | None
     - None
     - Optional penalty strength(s). Formula-level nonnegative values fix the corresponding smoothing parameters; negative entries request estimation.

Only supported formula options are shown here. Formula defaults come from the formula specification; k=-1 requests the basis-specific automatic rank, independently of runtime-constructor defaults. Runtime-only setup arguments belong to the separate implementation API. Point constraints and additional setup follow the capabilities below.

``pc`` (float or mapping, default None) imposes the function constraint f(x0)=0 through a basis reparameterization.

``xt`` (mapping, default None) supplies basis-specific setup: Required boundary setup under bnd: list of closed polygon mappings using the formula coordinate names. Optional nmax (default 200) controls grid resolution. A boundary f column supplies known boundary values. so combines boundary/interior, sf retains boundary film, sw retains the zero-boundary interior.

Identifiability, penalty and prediction
---------------------------------------

The basis penalty acts on fitted coefficient coordinates; requested rank k is not fitted EDF. Ordinary smooth centering separates the smooth from the model intercept, subject to the basis, numeric/factor by-variable and point-constraint rules. A point constraint replaces the relevant centering direction rather than fixing an arbitrary coefficient. Prediction reuses the fitted knots, constraints and penalty setup.

Out-of-range behavior is basis-specific and follows the retained fitted basis, rather than automatic expansion of its rank or knot domain. For bounded spatial domains and shape constraints, inspect the domain/constraint restrictions in the runtime notes before extrapolating.

Outputs
-------

The formula adds a term to the fitted model's additive predictor. Its coefficient block has p_term columns after constraints, potentially fewer than the requested k; this dimension differs from EDF. ``predict(type='terms')`` returns a floating array with n rows and one column per retained term for a scalar predictor. ``lpmatrix`` returns the full floating model design, shape (n, p), including the other terms. The scalar Gaussian examples below produce response predictions of shape (n,). Runtime matrix and penalty contracts are documented separately.
