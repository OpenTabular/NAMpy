Markov random field (``mrf``)
=============================

Markov random-field smooth for discrete regions. A neighborhood graph or supplied precision matrix penalizes differences between connected areas.

Theory and interpretation
-------------------------

A Markov random field treats discrete regions as vertices in a graph.
For an undirected adjacency matrix A and degree matrix D, the graph
Laplacian penalizes differences between neighboring region effects.

.. math::

   Q=D-A,\qquad J(b)=b^\mathsf TQb=\sum_{\{r,s\}\in E}(b_r-b_s)^2.

Connected regions borrow information; non-neighbors interact only
through graph paths. Each connected component contributes a constant
null-space direction, so centering and rank handling matter for
disconnected graphs. A reduced-rank constructor retains a subset of
graph directions; a supplied precision may define a different
quadratic relationship. The model is a discrete regional surface,
not a continuous interpolation between polygon centroids.

For coefficient coordinates, centering, null spaces and EDF, see
:doc:`/statistical_reference/smooths/theory`. The formula and runtime
contracts below specify which mathematical options NAMpy exposes.

Formula interface
-----------------

.. code-block:: python

   formula = "y ~ s(x, bs='mrf')"

Formula constructors are parsed inside strings; they are not Python functions. ``k``, ``m``, ``by``, ``id``, ``sp`` and ``fx`` configure the term where supported. Formula ``id`` maps to runtime ``smoothing_id`` and ``fx`` maps to ``fixed``.

Parameters
----------

   :header-rows: 1
   :class: api-reference-table

   * - Formula option
     - Type / shape
     - Default
     - Meaning
   * - ``bs``
     - str
     - ``model basis ('tp' by default)``
     - Select this basis with bs='mrf'. The alias basis is also accepted.
   * - ``k``
     - int
     - ``-1 (automatic)``
     - Retained MRF basis dimension, at most the number of region levels; negative selects the full region basis. Lower dimensions use a reduced-rank representation.
   * - ``m``
     - int | sequence | None
     - ``None``
     - Accepted by the common parser but not used by this basis.
   * - ``by``
     - str | expression | None
     - ``None``
     - Numeric multiplier or categorical source column/expression defining varying-coefficient or level-specific effects; evaluated on training and new rows.
   * - ``id``
     - str | int | None
     - ``None``
     - Share smoothing parameters across compatible terms. Alias smoothing_id is accepted; basis sharing follows id_links_bases.
   * - ``sp``
     - float | sequence[float] | None
     - ``None``
     - Penalty strengths in term penalty order. Nonnegative supplied values fix strengths; negative entries request estimation when automatic selection is enabled.
   * - ``xt``
     - mapping | sequence[mapping | None] | str | None
     - ``None``
     - Mapping with nb (named neighbor lists), penalty (supplied region precision matrix), or polys (named polygons used to derive neighbors). Matrix/graph names must match factor levels; a supplied penalty takes precedence.
   * - ``fx``
     - bool
     - ``False``
     - Fit the smooth without its roughness penalty. Model-level null-space selection cannot be combined with a fixed unpenalized term.

The formula compiler resolves defaults independently of runtime constructors. ``knots`` and ``select`` belong to the model, not the formula call. Runtime-only setup options are documented in the implementation API.

Identifiability, penalty and prediction
---------------------------------------

The basis penalty acts on fitted coefficient coordinates; requested rank k is not fitted EDF. Ordinary smooth centering separates the smooth from the model intercept, subject to the basis, numeric/factor by-variable and point-constraint rules. A point constraint replaces the relevant centering direction rather than fixing an arbitrary coefficient. Prediction reuses the fitted knots, constraints and penalty setup.

Prediction uses fitted region/group levels rather than continuous extrapolation. Random-effect terms give unseen levels zero contribution; MRF terms reject unknown regions.

Outputs
-------

The formula adds a term to the fitted model's additive predictor. Its coefficient block has p_term columns after constraints; this dimension differs from EDF. ``predict(type='terms')`` returns a floating array with n rows and one column per retained term for a scalar predictor. ``lpmatrix`` returns the full floating model design, shape (n, p), including the other terms. The scalar Gaussian examples below produce response predictions of shape (n,). Runtime matrix and penalty contracts are documented separately.
