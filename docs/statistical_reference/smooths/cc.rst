Cyclic cubic spline (``cc``)
============================

Cyclic cubic regression spline. The fitted effect joins smoothly at the period boundaries; use this for a genuinely periodic covariate.

Theory and interpretation
-------------------------

The cyclic construction identifies the ends of the domain.
For cyclic cubics, function value and the first two derivatives
match at the boundary; cyclic P-splines wrap the basis and
coefficient differences.

.. math::

   f(a)=f(b),\qquad f^{(j)}(a)=f^{(j)}(b)\quad\text{for the matched derivative orders}.

Periodicity removes a discontinuity at the seam, as needed for
hour of day or season. It replaces the ordinary open-boundary
behavior described above; a nonconstant straight line is not a
periodic null-space function. Supply boundaries that represent a
full scientific period, rather than relying on an accidentally
truncated observed range.

The cyclic cubic penalty still measures integrated
squared curvature, now in a periodic rather than natural
open-boundary function space.

.. math::

   J(f)=\int_a^b\{f''(x)\}^2dx=\beta^\mathsf TS_{\mathrm{cyclic}}\beta.

Its smoothest periodic direction is constant. After
centering against an intercept, increasing lambda can suppress
the remaining seasonal variation. k controls the periodic
approximation space; lambda controls how much variation is
supported within that space.

For coefficient coordinates, centering, null spaces and EDF, see
:doc:`/statistical_reference/smooths/theory`. The formula and runtime
contracts below specify which mathematical options NAMpy exposes.

Formula interface
-----------------

.. code-block:: python

   formula = "y ~ s(x, bs='cc')"

Formula constructors are parsed inside strings; they are not Python functions. ``k``, ``m``, ``by``, ``id``, ``sp`` and ``fx`` configure the term where supported. Formula ``id`` maps to runtime ``smoothing_id`` and ``fx`` maps to ``fixed``.

Identifiability, penalty and prediction
---------------------------------------

The basis penalty acts on fitted coefficient coordinates; requested rank k is not fitted EDF. Ordinary smooth centering separates the smooth from the model intercept, subject to the basis, numeric/factor by-variable and point-constraint rules. A point constraint replaces the relevant centering direction rather than fixing an arbitrary coefficient. Prediction reuses the fitted knots, constraints and penalty setup.

New covariate values use the fitted periodic domain; matching boundary behavior is part of the cyclic construction. The cycle boundaries must represent a real period in the data.

Outputs
-------

The formula adds a term to the fitted model's additive predictor. Its coefficient block has p_term columns after constraints; this dimension differs from EDF. ``predict(type='terms')`` returns a floating array with n rows and one column per retained term for a scalar predictor. ``lpmatrix`` returns the full floating model design, shape (n, p), including the other terms. The scalar Gaussian examples below produce response predictions of shape (n,). Runtime matrix and penalty contracts are documented separately.
