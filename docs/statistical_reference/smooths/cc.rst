cc
==

Cyclic cubic regression spline. The fitted effect joins smoothly at the period boundaries; use this for a genuinely periodic covariate.

Formula interface
-----------------

.. code-block:: python

   formula = "y ~ s(x, bs='cc')"

Formula constructors are parsed inside strings; they are not Python functions. ``k``, ``m``, ``by``, ``id``, ``sp`` and ``fx`` configure the term where supported. Formula ``id`` maps to runtime ``smoothing_id`` and ``fx`` maps to ``fixed``.

Outputs
-------

The constructor returns an unfitted runtime term. ``fit(X, feature_names)`` initializes its basis and penalties and returns the term. ``transform_new(X_new)`` returns a dense ``(n_samples, n_term_coefficients)`` matrix in the fitted constraint coordinates. ``penalties`` returns the term's penalty matrices, each square in those coefficient coordinates. The term contributes ``transform_new(X_new) @ coefficients`` on the additive predictor scale. Basis dimension can decrease after constraints; it is distinct from fitted EDF.

Implementation notes
--------------------

Cubic regression spline smooth term (``bs='cr'``).

Implements the :class:`BaseSmoothTerm` interface for a single-variable cubic
regression spline basis with a second-derivative penalty.  Knots are either
user-supplied or chosen automatically using quantiles of the training data.

An optional null-space selection penalty is added when ``select=True``,
allowing the term to be shrunk to zero.

A point constraint ``coef[i] = 0`` may be specified via the ``pc`` argument
to pin a basis function to a fixed value (used for derivative computation and
identifiability in some settings).
