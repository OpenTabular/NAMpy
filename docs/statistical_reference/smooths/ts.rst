ts
==

Thin-plate shrinkage spline. A modified full-rank penalty also shrinks the polynomial null space, allowing the whole term to approach zero.

Formula interface
-----------------

.. code-block:: python

   formula = "y ~ s(x, bs='ts')"

Formula constructors are parsed inside strings; they are not Python functions. ``k``, ``m``, ``by``, ``id``, ``sp`` and ``fx`` configure the term where supported. Formula ``id`` maps to runtime ``smoothing_id`` and ``fx`` maps to ``fixed``.

Outputs
-------

The constructor returns an unfitted runtime term. ``fit(X, feature_names)`` initializes its basis and penalties and returns the term. ``transform_new(X_new)`` returns a dense ``(n_samples, n_term_coefficients)`` matrix in the fitted constraint coordinates. ``penalties`` returns the term's penalty matrices, each square in those coefficient coordinates. The term contributes ``transform_new(X_new) @ coefficients`` on the additive predictor scale. Basis dimension can decrease after constraints; it is distinct from fitted EDF.

Implementation notes
--------------------

Thin plate regression spline smooth term (``bs='tp'`` / ``bs='ts'``).

Implements the :class:`BaseSmoothTerm` interface for a rank-reduced thin plate
spline basis.  Thin plate splines are rotation-invariant and automatically
extend to multi-variate smooths, making them the default smooth type.

The ``'ts'`` variant uses a shrinkage version of the main thin-plate penalty,
making the penalty full-rank so the term can shrink entirely to zero.
Separately, ``select=True`` adds an explicit null-space selection penalty on
top of the main penalty.
