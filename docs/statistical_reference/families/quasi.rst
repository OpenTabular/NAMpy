quasi
=====

.. math::

   \frac{\partial Q(y,\mu)}{\partial\mu}=\frac{y-\mu}{\phi V(\mu)}

* **Natural domains:** :math:`\mu\in\operatorname{dom}(g),\quad\phi>0`
* **Conditional mean:** :math:`\mathbb E[Y\mid x]=\mu`
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=\phi V(\mu)`

Quasi-likelihood specifies a mean-variance relationship, not a normalized probability density.

A likelihood-based AIC is unavailable for a quasi-likelihood family. Deviance and Pearson residuals retain their estimating-equation meanings.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

Quasi-likelihood specifies a mean and variance function without
a complete probability density. Its estimating equation weights
residuals by the inverse of the assumed variance.

.. math::

   \frac{\partial Q(y,\mu)}{\partial\mu}=\frac{y-\mu}{\phi V(\mu)}.

Quasi-Poisson takes V(mu)=mu; quasi-binomial takes
V(mu)=mu*(1-mu), with the documented trial convention. Phi can
allow extra variation while retaining a mean-link model. This
does not supply probabilities for new observations, so normalized
likelihood comparisons and likelihood-based AIC are unavailable.
Mean-model diagnostics still depend on an adequate variance
relation and independence assumptions.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Quasi-likelihood mean/variance model. Choose link, variance function and optional power. It does not define a normalized probability distribution.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'quasi'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Signature
---------

.. code-block:: python

   QuasiFamily(link='identity', variance='constant', *, power=None, **kwargs)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``link``
     - ``str``
     - ``'identity'``
     - Single named link string. Supported names and formulas are in the link reference; sequences are not accepted here.
   * - ``variance``
     - ``str``
     - ``'constant'``
     - One of constant, mu, mu(1-mu), mu^2 or mu^3 (spaces are removed). This selects V(mu), independently of the link exponent.
   * - ``power``
     - ``float | None``
     - ``None``
     - Finite numeric quasi link exponent, independent of variance: values <=0 choose log, 1 chooses identity, and other positive values choose mu**power. None uses the named link; incompatible named links are rejected.
   * - ``kwargs``
     - ``keyword arguments``
     - Variable arguments
     - Direct-class inherited eps (float, default 1e-9). The named quasi classes also forward power (float | None, default None) under its link compatibility rules. Factory mappings accept only their explicitly listed options; see the general quasi configuration contract.

The constructor returns a family object, not predictions. ``GAM.fit`` returns the fitted model. For a single-predictor family, ``GAM.predict(type='response')`` normally returns a response-scale array, while ``type='link'`` returns the additive predictor. Multi-predictor families have family-specific response transformations. ``GAMLSS.predict`` exposes natural distribution parameters; ``predict(raw=True)`` exposes link predictors. These interfaces can have different column meanings.
