gevlss
======

Generalized extreme-value location, scale and shape regression with three predictors and parameter-dependent response support.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'gevlss'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Signature
---------

.. code-block:: python

   GevlssFamily(link=('identity', 'identity', 'logit'))

Distribution definition and moments
-----------------------------------

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Quantity
     - Definition
   * - Distribution / loss
     - F(y)=exp(-(1+xi (y-mu)/sigma)^(-1/xi)); support 1+xi(y-mu)/sigma>0. The xi=0 limit is Gumbel.
   * - Natural domains
     - mu in R; sigma>0; shape xi subject to the configured link bounds
   * - Conditional mean
     - mu+sigma (Gamma(1-xi)-1)/xi for xi<1 (continuous xi=0 limit); undefined otherwise
   * - Conditional variance
     - sigma^2 (Gamma(1-2xi)-Gamma(1-xi)^2)/xi^2 for xi<1/2; infinite otherwise

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

The constructor returns a family object, not predictions. ``GAM.fit`` returns the fitted model. For a single-predictor family, ``GAM.predict(type='response')`` normally returns a response-scale array, while ``type='link'`` returns the additive predictor. Multi-predictor families have family-specific response transformations. ``GAMLSS.predict`` exposes natural distribution parameters; ``predict(raw=True)`` exposes link predictors. These interfaces can have different column meanings.

Parameterization and interpretation
-----------------------------------


``gevlss(link=("identity", "identity", "logit"))`` has three predictors.
Location accepts identity/log, log scale accepts identity, and shape accepts
identity or a shifted logit confining it to ``(-1, 0.5)``.
Source response prediction returns ``(mu, log_sigma, xi)``;
``GAMLSS.predict`` returns ``(mu, sigma, xi)``. The point prediction uses the
same conditional-mean expression as source residuals.

All four link combinations have analytic first-through-fourth derivative,
initialization, density and residual references. Identity/log-location
fixed/selected REML fits have coefficient, covariance, criterion/EDF and
prediction/SE references. Source likelihood evaluation replaces tiny shapes
by signed ``+/-1e-7``; it has no separate zero-shape derivative branch.
Simulation uses the source inverse CDF and its ``1e-8`` shape cutoff.

The source residual mean is computed before its shape cutoff, retaining an
undefined ratio at exactly ``xi=0``. Its Pearson denominator retains the
source ``exp(rho)/xi`` sign. Deviance residuals retain source scaling without
an added factor two; null deviance is undefined. Public density is negative
infinity outside support; invalid source likelihood trials remain nonfinite
for the existing fit-step checks. Example: ``examples/example_gevlss_gam.py``.
