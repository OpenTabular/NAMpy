bcg
===

.. math::

   h_\lambda(y)=\begin{cases}(y^\lambda-1)/\lambda&\lambda\ne0,\\\log y&\lambda=0,\end{cases}\quad Z=h_\lambda(Y)

* **Natural domains:** :math:`Y>0,\ \mu,\lambda\in\mathbb R,\ \sigma>0`; inverse transformation requires :math:`1+\lambda Z>0`.
* **Conditional mean:** :math:`\mathbb E[Z\mid x]=\mu,\quad\mathbb E[Y\mid x]=\mathbb E[h_\lambda^{-1}(Z)\mid x]`; at :math:`\lambda=0`, :math:`\mathbb E[Y\mid x]=e^{\mu+\sigma^2/2}`.
* **Conditional variance:** :math:`\operatorname{Var}(Z\mid x)=\sigma^2`; response variance is :math:`\mathbb E[h_\lambda^{-1}(Z)^2\mid x]-\mathbb E[h_\lambda^{-1}(Z)\mid x]^2`. At :math:`\lambda=0`: :math:`(e^{\sigma^2}-1)e^{2\mu+\sigma^2}`. These formulas use unit prior weight.

uncensored Gaussian transformation kernel :math:`\varphi\!\left(\frac{h_\lambda(y)-\mu}{\sigma}\right)\frac{y^{\lambda-1}}{\sigma}`

Targets include censoring bounds rather than treating bounds as ordinary observations. The worked example and parameterization notes below define the exact two-column encoding and one-sided sentinel convention.

Box-Cox response moments require an inverse-transform calculation on its valid domain and need not exist for all negative-shape tails. NAMpy preserves the upstream transformed-response likelihood and returns the transformed Gaussian location; it does not return an inverse-transform response mean. Prior weight :math:`w` rescales transformed variance to :math:`\sigma^2/w`.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

`Upstream bcg parameterization <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/bcg.html>`_.

Censoring describes partial knowledge of a latent response.
An interval contributes its probability mass, rather than the
density at either endpoint. A right-censored value contributes a
survival probability.

.. math::

   \ell_i=\begin{cases}\log f(y_i)&\text{exact},\\\log\{F(u_i)-F(l_i)\}&\text{continuous interval},\\\log\{1-F(l_i)\}&\text{right censored}.\end{cases}

For closed integer Poisson intervals use F(u)-F(l-1).
Replacing a bound with an ordinary observed response biases the
target. Censoring models the observation process while retaining
the latent law's parameters and moments. Truncation, which
conditions on inclusion in the sample, requires a different
likelihood normalization. Follow the exact target encoding
below, including its endpoint and one-sided conventions.

The Box-Cox transformation additionally contributes its Jacobian for exact observations. Its Gaussian location is on the transformed scale; inverse-transforming that location is not generally the response mean.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Censored Box-Cox Gaussian response, with transformation and scale nuisance parameters.

Usage

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Parameterization and interpretation
-----------------------------------

``CensoredBoxCoxGaussianFamily(theta=None, link="identity")`` implements
``family="bcg"``. One predictor describes Gaussian location after a Box-Cox
response transformation; links are identity, log and square root.
``getTheta()`` returns lambda and log SD, and ``getTheta(trans=True)``
transforms the second entry to SD. The default estimates both parameters,
starting at working values ``[1, 0]``. Positive precision weights replace
log SD by ``logSD - log(weight)/2``.

Censoring uses explicit paired response data. Nonpositive second-column
values denote left censoring, positive unequal finite endpoints denote an
interval, and ``+Inf`` denotes right censoring. Source initialization uses the
input response scale. Predictions describe the transformed Gaussian location;
they do not apply an inverse Box-Cox mean correction.

The source fixed constructor has a specific failure: positive
``theta=[lambda, sd]`` stores three working entries,
``[lambda, log(lambda), log(sd)]``. Its fitted source call fails with an
``ls$lsth2`` indexing error. NAMpy rejects this malformed fitted state with
``ValueError``. The source-owned setter provides an explicit supported
working-state route:

.. code-block:: python

   import numpy as np
   from nampy.gam.families import CensoredBoxCoxGaussianFamily

   family = CensoredBoxCoxGaussianFamily(theta=[0.7, 0.8])
   family.putTheta([0.7, np.log(0.8)])

The family remains fixed, with a coherent two-entry working state; no automatic
constructor repair is performed. A nonpositive second constructor entry starts
estimation and retains that entry as the initial working log SD, following
source initialization order.

References cover the near-zero-lambda expansions, all censor blocks, fourth
location and second ancillary derivatives, exact and mixed responses,
precision weights, offsets, fixed/estimated ancillary parameters, and
fixed/ML/REML smoothing. Estimated-parameter vector fits cover all three links.
EFS uses the two-parameter source ``estimate.theta`` update inside PIRLS;
fixed/estimated ancillary vector and mixed-response endpoints have direct
references. Theta-update references also cover external dispersion one/two;
the captured scale-two source updates warn about step failure and retain their
returned state. Estimating ancillary parameters with EFS requires a free
smoothing parameter: the all-fixed-SP source call errors. Positive ``min_sp``
and rank-deficient outer-uncertainty combinations retain the extended-family
guards described above.

Source AIC omits scale/Box-Cox Jacobians and is not an independently normalized
Box-Cox density. Source saturated-likelihood derivative arrays are zero despite
the value's ancillary dependence. Exactly transformed censor endpoints can
produce source NaNs in signed density differences; those NaNs remain visible.
Quantile and simulation hooks are unavailable. See ``examples/example_bcg_gam.py``.
Source: mgcv 1.9-4 ``R/efam.r::bcg, estimate.theta`` and ``R/gam.fit4.r``.
