gammals
=======

Gamma location-scale regression with two additive predictors for log mean and log dispersion under the source family parameterization.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'gammals'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Signature
---------

.. code-block:: python

   GammalsFamily(link=('identity', 'log'), b: 'float' = -7.0)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``link``
     - ``Sequence[str], one per linear predictor``
     - ``('identity', 'log')``
     - Link name or ordered sequence of links. Supported choices and interpretation are specific to this family; sequence order follows its linear predictors.
   * - ``b``
     - ``float``
     - ``-7.0``
     - Lower bound for log dispersion under the source lower-bounded log link; default -7. It is not a lower bound for Gaussian standard deviation.

   * - Entry point

   * - constructor
     - BaseFamily subclass
     - scalar object
     - Independent mutable response-family state, not predictions.
   * - GAM.predict(type='link')
     - numpy.ndarray[float64]
     - (n, 2)
     - Additive predictor columns, before family response transformations.
   * - GAM.predict(type='response')
     - numpy.ndarray[float64]
     - (n, 2)
     - Source linked-family response columns; these are distinct from the natural (mean, coefficient-of-variation) interface below.
   * - Natural parameter interface
     - numpy.ndarray[float64]
     - (n, 2)
     - Natural columns: mu, sigma. Used by GAMLSS.predict and distribution_parameters_from_eta. sigma is the positive coefficient of variation: sigma=exp(log_dispersion/2), Var(Y)=(mu*sigma)**2; it is not a Gaussian SD or Gamma rate.

The constructor returns a family object, not predictions. ``GAM.fit`` returns the fitted model. For a single-predictor family, ``GAM.predict(type='response')`` normally returns a response-scale array, while ``type='link'`` returns the additive predictor. Multi-predictor families have family-specific response transformations. ``GAMLSS.predict`` exposes natural distribution parameters; ``predict(raw=True)`` exposes link predictors. These interfaces can have different column meanings.
