cpois
=====

Theory and interpretation
-------------------------

* **Distribution / loss:** Latent P(Y=j)=exp(-lambda)lambda^j/j!, j=0,1,.... Censoring contributions follow the documented exact/interval/one-sided encoding.
* **Natural domains:** lambda>0
* **Conditional mean:** lambda
* **Conditional variance:** lambda

Targets include censoring bounds rather than treating bounds as ordinary observations. The worked example and parameterization notes below define the exact two-column encoding and one-sided sentinel convention.

For a closed integer interval [l,u], its probability is F(u)-F(l-1); continuous endpoint formulas must not be applied to integer intervals without the discrete correction.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

Censoring describes partial knowledge of a latent response.
An interval contributes its probability mass, rather than the
density at either endpoint. A right-censored value contributes a
survival probability.

.. math::

   \ell_i=\begin{cases}\log f(y_i)&\text{exact},\\\log\{F(u_i)-F(l_i)\}&\text{continuous interval},\\\log\{1-F(l_i)\}&\text{right censored}.\end{cases}

For closed integer Poisson intervals use F(u)-F(l-1).
Replacing a bound with an ordinary observed response biases the
target. Censoring models the observation process while retaining
the latent law's parameters and moments. Truncation, which
conditions on inclusion in the sample, requires a different
likelihood normalization. Follow the exact target encoding
below, including its endpoint and one-sided conventions.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Censored Poisson counts with censoring bounds in the response encoding; default log link.

Parameterization and interpretation
-----------------------------------

``CensoredPoissonFamily(link="log")`` implements ``family="cpois"``.
The predictor models the latent Poisson mean, using a log, identity or
square-root link. There are no ancillary distribution parameters to estimate.
Use ``cbind(value, bound)`` for censoring: equal endpoints denote an exact
count, ``-Inf`` denotes left censoring and ``+Inf`` right censoring. A finite
unequal pair denotes the discrete event ``min(value,bound) < Y <= max(value,bound)``.
For example, ``[2, 4]`` includes counts three and four. Predictions return the
underlying mean, with standard errors for that mean.

The source likelihood, deviance, saturated likelihood and derivative hooks
ignore observation weights. They are not frequency-weighted Poisson hooks;
nonunit-weight reference fits retain this source convention. Density and tail
probabilities follow the scalar R Mathlib ``dpois``/``ppois`` branches, including
extreme-tail and degenerate-mean cases. Location derivatives through fourth
order, the discrete saturated-likelihood correction, residuals and null
calculations use those source probabilities.

Actual-mgcv fixtures cover exact/mixed responses, all three links, fixed
smoothing, ML/REML selection, positive external dispersion and observation weights,
coefficients, covariance, EDF, likelihood criteria, residuals and predictions/SE.
The alternative ``bfgs``, ``optim``, ``nlm`` and ``efs`` routes have direct
references. The nlm comparison uses matching tighter controls:
``control={"epsilon": 1e-10, "nlm": {"gradtol": 1e-10, "steptol": 1e-10}}``.
Source quantile and simulation hooks are unavailable. See
``examples/example_cpois_gam.py``. Source: mgcv 1.9-4 ``R/efam.r::cpois``
and the R Mathlib Poisson density/tail routines.
