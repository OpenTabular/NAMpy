gaulss
======

Gaussian location-scale regression with two additive predictors. The first models mean; the second models inverse standard deviation through the logb link.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'gaulss'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Signature
---------

.. code-block:: python

   GaulssFamily(link=('identity', 'logb'), b: 'float' = 0.01)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``link``
     - ``Sequence[str], one per linear predictor``
     - ``('identity', 'logb')``
     - Link name or ordered sequence of links. Supported choices and interpretation are specific to this family; sequence order follows its linear predictors.
   * - ``b``
     - ``float``
     - ``0.01``
     - Lower bound on standard deviation, default 0.01. With second predictor eta, sigma=b+exp(eta) and internal precision tau=1/sigma.

The constructor returns a family object, not predictions. ``GAM.fit`` returns the fitted model. For a single-predictor family, ``GAM.predict(type='response')`` normally returns a response-scale array, while ``type='link'`` returns the additive predictor. Multi-predictor families have family-specific response transformations. ``GAMLSS.predict`` exposes natural distribution parameters; ``predict(raw=True)`` exposes link predictors. These interfaces can have different column meanings.
