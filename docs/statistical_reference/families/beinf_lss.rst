beinf_lss
=========

.. math::

   p_Y(y)=\begin{cases}\pi_0&y=0,\\\pi_1&y=1,\\\pi_I f_{\mathrm{Beta}}(y;\mu\phi,(1-\mu)\phi)&0<y<1,\end{cases}\quad\pi_I=1-\pi_0-\pi_1

* **Natural domains:** :math:`0<\mu<1,\quad\phi>0,\quad\pi_0,\pi_1,\pi_I\geq0,\quad\pi_0+\pi_1+\pi_I=1`
* **Conditional mean:** :math:`m=\mathbb E[Y\mid x]=\pi_1+\pi_I\mu`
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=\pi_I\left[\frac{\mu(1-\mu)}{1+\phi}+(\mu-m)^2\right]+\pi_0m^2+\pi_1(1-m)^2`

Four formula keys are ``mu, phi, pi0, pi1``. Natural columns are ``mu, phi, pi0, pi1, pi_interior``; raw columns are logit(mu), log(phi), log(pi0/pi_interior), log(pi1/pi_interior). The last two are coupled category log ratios, not independent probability logits. Components contain exactly four predictors; the interior probability depends on both atom predictors and has no separate term. Full covariance is retained for all five natural errors. R BEINF uses sigma=1/sqrt(1+phi), nu=pi0/pi_interior, tau=pi1/pi_interior. All components and distinct interior observations are required for fitting; neural fitting uses its normalized likelihood. The saved gamlss.dist 6.1.1 variance hook adds rather than subtracts squared mean; NAMpy uses the normalized mixture variance and records this discrepancy.

Distribution reference: `gamlss.dist::BEINF <https://github.com/cran/gamlss.dist/blob/master/man/BEINF.Rd>`_. Fitting uses NAMpy's joint penalized engine, not gamlss RS backfitting. See :doc:`/development/neighbor_parity` for the tested mapping and numerical comparisons.

Fixed smoothing and automatic general-family REML with outer_newton, bfgs and efs are validated. Method labels retain mgcv general-family coercion to REML; this is not separate ML/GCV/UBRE/NCV support. The optim route is unavailable because the extension has no family-defined null deviance for its objective scaling; magic and nlm.fd are also unsupported. Native deviance residuals and null deviance are unavailable; shared distribution quantile residuals are available. Censoring, truncation and alternate links are unsupported. Existing transformed-coefficient/observation and general-NCV guards remain in force.

Inflated beta regression models exact zeros and ones separately
from continuous proportions inside the unit interval. Mu and phi
describe the interior component, not the whole-response mean.

.. math::

   (\pi_0,\pi_1,\pi_I)=\frac{(e^{\eta_0},e^{\eta_1},1)}{1+e^{\eta_0}+e^{\eta_1}},\qquad E[Y]=\pi_1+\pi_I\mu.

Both atom probabilities depend on both atom predictors. Their
errors therefore need cross-predictor covariance. The interior
category is the reference: it has a derived probability and no independent fifth predictor.
Fitting requires observations from every component and distinct
interior responses. Absent components have no validated finite statistical fit; normalized probability queries allow boundary weights.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Types, defaults and output shapes
---------------------------------

.. autoclass:: nampy.gam.families.gamlss.inflated_beta.InflatedBeta

Pass ``GAMLSS(family='beinf_lss')``; this family has no constructor options.

``predict_parameters(X)`` returns natural parameters as a float ``(n,5)`` array, ``predict_link(X)`` returns link predictors ``(n,4)``, ``predict_point(X)`` returns the conditional mean ``(n,)``, and ``predict_components(X)`` returns an AdditivePrediction whose link and each term are ``(n,4)``. ``X`` is a DataFrame or numeric ``(n,d)`` array, consistent with formula mode.

Likelihood derivatives through order four are analytic, including mixed derivatives. Fixed smoothing is tested; automatic smoothing requires an enabled runtime capability and route-specific evidence. Residual availability follows the observation contract; ordinary response/Pearson residuals are unavailable for censored targets. Deviance residuals and null deviance are not defined by this implementation; use explicit response/Pearson diagnostics or shared distribution quantile residuals rather than the default deviance-residual plotting workflow.
