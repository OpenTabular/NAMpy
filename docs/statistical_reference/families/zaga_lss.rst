zaga_lss
========

.. math::

   p_Y(y)=\begin{cases}\pi_0&y=0,\\(1-\pi_0)\,f_\Gamma(y;a,\theta)&y>0,\end{cases}\quad a=\sigma^{-2},\ \theta=\mu\sigma^2

* **Natural domains:** :math:`\mu>0,\quad\sigma>0,\quad0\leq\pi_0\leq1,\quad y\geq0`
* **Conditional mean:** :math:`\mathbb E[Y\mid x]=(1-\pi_0)\mu`
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=(1-\pi_0)\mu^2(\sigma^2+\pi_0)`

Natural columns are ``mu, sigma, pi0`` with log/log/logit links. Mu is the positive Gamma mean, sigma its coefficient of variation, and pi0 the exact zero probability (gamlss.dist ZAGA calls it nu). The whole-response mean is (1-pi0)*mu. Log probability reports mass at zero and density elsewhere. Finite-logit fitting requires both components and distinct positive observations; exact zero/one atom probabilities are available only for probability queries. Neural ZAGA fitting uses its normalized likelihood.

Distribution reference: `gamlss.dist::ZAGA <https://github.com/cran/gamlss.dist/blob/master/man/ZAGA.Rd>`_. Fitting uses NAMpy's joint penalized engine, not gamlss RS backfitting. See :doc:`/development/neighbor_parity` for the tested mapping and numerical comparisons.

Fixed smoothing and automatic general-family REML with outer_newton, bfgs and efs are validated. Method labels retain mgcv general-family coercion to REML; this is not separate ML/GCV/UBRE/NCV support. The optim route is unavailable because the extension has no family-defined null deviance for its objective scaling; magic and nlm.fd are also unsupported. Native deviance residuals and null deviance are unavailable; shared distribution quantile residuals are available. Censoring, truncation and alternate links are unsupported. Existing transformed-coefficient/observation and general-NCV guards remain in force.

Zero-adjusted Gamma regression separates exact zeros from positive
continuous outcomes. The Gamma component cannot generate zeros, so
the atom probability is identifiable from the zero indicator.

.. math::

   P(Y=0)=\pi_0,\qquad Y\mid Y>0\sim\mathrm{Gamma}(\sigma^{-2},\mathrm{scale}=\mu\sigma^2).

Mu is the positive-component mean and sigma its coefficient of
variation. Whole-response means combine both mechanisms. Fitting uses
log/log/logit predictors and requires observed zeros plus distinct
positive responses. Absent components have no finite-logit fit here.
Fixed smoothing and validated joint REML routes are supported;
this does not imply gamlss RS/backfitting parity or parity of optimization paths. Neural fitting uses the normalized likelihood.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Types, defaults and output shapes
---------------------------------

.. autoclass:: nampy.gam.families.gamlss.semicontinuous.ZeroAdjustedGamma

Pass ``GAMLSS(family='zaga_lss')``; this family has no constructor options.

``predict(X)`` returns natural parameters as a float ``(n,3)`` array, ``predict(X, raw=True)`` returns link predictors ``(n,3)``, ``predict_point(X)`` returns the conditional mean ``(n,)``, and ``predict_components(X)`` returns an AdditivePrediction whose link and each term are ``(n,3)``. ``X`` is a DataFrame or numeric ``(n,d)`` array, consistent with formula mode.

Likelihood derivatives through order four are analytic, including mixed derivatives. Fixed smoothing is tested; automatic smoothing requires an enabled runtime capability and route-specific evidence. Residual availability follows the observation contract; ordinary response/Pearson residuals are unavailable for censored targets. Deviance residuals and null deviance are not defined by this implementation; use explicit response/Pearson diagnostics or shared distribution quantile residuals rather than the default deviance-residual plotting workflow.
