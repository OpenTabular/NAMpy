normal_observation_lss
======================

.. math::

   f_T(y)=f_N(y)/Z,\quad Z=F_N(U)-F_N(L)

* **Natural domains:** :math:`\mu\in\mathbb R,\ \sigma>0,\ L<U`
* **Conditional mean:** :math:`E_T[Y]=\mu+\sigma\{\varphi(a)-\varphi(b)\}/Z` with a=(L-mu)/sigma, b=(U-mu)/sigma; distinct from latent location.
* **Conditional variance:** :math:`Var_T(Y)=\sigma^2[1+\{a\varphi(a)-b\varphi(b)\}/Z-(\{\varphi(a)-\varphi(b)\}/Z)^2]` with infinite endpoint products defined by their zero limits.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

Normal location-scale predictions may be conditioned on fixed truncation bounds. ObservationTarget separately records exact, left/right-censored and interval observations.

.. math::

   \ell=\log f_N(y)-\log Z\text{ (exact)},\quad\ell=\log\{F_N(b)-F_N(a)\}-\log Z\text{ (censored)}.

Truncation changes the response law; censoring changes the observed likelihood. Statistical fitting uses the existing joint adapter and analytic fourth-order derivatives. Neural fitting uses a differentiable normalized loss. Bounds are observation metadata, not weights. Source-specific mgcv cnorm behavior is unchanged. Variable truncation bounds and discrete/mixed observation compositions are unsupported.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Types, defaults and output shapes
---------------------------------

.. autoclass:: nampy.gam.families.gamlss.observations.NormalObservations

Use family={'name': 'normal_observation_lss', 'lower': L, 'upper': U} for fixed truncation and supply ObservationTarget to fit. Defaults leave both tails untruncated.

``predict_parameters(X)`` returns natural parameters as a float ``(n,2)`` array, ``predict_link(X)`` returns link predictors ``(n,2)``, ``predict_point(X)`` returns the conditional mean ``(n,)``, and ``predict_components(X)`` returns an AdditivePrediction whose link and each term are ``(n,2)``. ``X`` is a DataFrame or numeric ``(n,d)`` array, consistent with formula mode.

Likelihood derivatives through order four are analytic, including mixed derivatives. Fixed smoothing is tested; automatic smoothing requires an enabled runtime capability and route-specific evidence. Residual availability follows the observation contract; ordinary response/Pearson residuals are unavailable for censored targets. Deviance residuals and null deviance are not defined by this implementation; use explicit response/Pearson diagnostics or shared distribution quantile residuals rather than the default deviance-residual plotting workflow.
