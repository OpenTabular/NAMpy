bct_lss
=======

.. math::

   f_Y(y)=\frac{(y/\mu)^\nu f_{t_\tau}(z)}{\sigma y F_{t_\tau}(1/(\sigma|\nu|))},\quad z=\frac{(y/\mu)^\nu-1}{\nu\sigma}

* **Natural domains:** :math:`y,\mu,\sigma,\tau>0,\quad\nu\in\mathbb R`; at nu=0, z=log(y/mu)/sigma and the normalizer is one. Tau is Student degrees of freedom.
* **Conditional mean:** :math:`E[Y]=M_1,\quad M_k=\int_0^\infty y^k f_Y(y)\,dy`; mu is a transformation parameter, not the response mean. The integral may diverge.
* **Conditional variance:** :math:`\operatorname{Var}(Y)=M_2-M_1^2` when both moments are finite. Shared prediction laws check moment existence explicitly.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

BCT models positive responses through a Box-Cox transformation with a normalized Student-t latent law. Four predictors describe mu, sigma, power nu and Student degrees of freedom tau; mu is not generally the response mean.

.. math::

   \eta=(\log\mu,\log\sigma,\nu,\log\tau),\quad f_Y(y)=f_{t_\tau}(z)\frac{(y/\mu)^\nu}{\sigma y F_{t_\tau}(1/(\sigma|\nu|))}.

The Jacobian and support probability are both fitted. The Student law is retained above the upstream density-only Gaussian-switch threshold. Statistical fitting uses the existing joint solver with exact first and second observed derivatives and fixed smoothing. Automatic smoothing is guarded until higher derivatives are validated. Neural normalizer gradients use checked vector CPU quadrature and support first-order autograd. At nu=0, BCT requires tau greater than the requested derivative order. Response moments may diverge and are checked separately by the prediction law.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Types, defaults and output shapes
---------------------------------

.. autoclass:: nampy.gam.families.gamlss.boxcox_tail.BCTLikelihood

Pass ``GAMLSS(family='bct_lss')``; this family has no constructor options.

``predict(X)`` returns natural parameters as a float ``(n,4)`` array, ``predict(X, raw=True)`` returns link predictors ``(n,4)``, ``predict_point(X)`` returns the conditional mean ``(n,)``, and ``predict_components(X)`` returns an AdditivePrediction whose link and each term are ``(n,4)``. ``X`` is a DataFrame or numeric ``(n,d)`` array, consistent with formula mode.

Likelihood derivatives through order two are analytic, including mixed derivatives. Fixed smoothing is tested; automatic smoothing requires an enabled runtime capability and route-specific evidence. Residual availability follows the observation contract; ordinary response/Pearson residuals are unavailable for censored targets. Deviance residuals and null deviance are not defined by this implementation; use explicit response/Pearson diagnostics or shared distribution quantile residuals rather than the default deviance-residual plotting workflow.
