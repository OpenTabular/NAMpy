bcpe_lss
========

.. math::

   f_Y(y)=\frac{(y/\mu)^\nu f_{PE}(z;\tau)}{\sigma y F_{PE}(1/(\sigma|\nu|);\tau)},\quad z=\frac{(y/\mu)^\nu-1}{\nu\sigma}

* **Natural domains:** :math:`y,\mu,\sigma,\tau>0,\quad\nu\in\mathbb R`; at nu=0, z=log(y/mu)/sigma and the normalizer is one. The latent PE has variance one; tau=2 gives BCCG.
* **Conditional mean:** :math:`E[Y]=M_1,\quad M_k=\int_0^\infty y^k f_Y(y)\,dy`; mu is not generally the response mean. Moments are evaluated only when finite.
* **Conditional variance:** :math:`\operatorname{Var}(Y)=M_2-M_1^2` when both moments are finite; shared prediction laws check existence explicitly.

:math:`f_{PE}(z;\tau)=\frac{\tau e^{-(|z|/\alpha)^\tau}}{2\alpha\Gamma(1/\tau)},\quad\alpha=\sqrt{\Gamma(1/\tau)/\Gamma(3/\tau)}`

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

BCPE replaces the Box-Cox Gaussian latent law with a variance-one power exponential. Four predictors describe mu, sigma, power nu and shape tau. Shape two is BCCG; larger shapes have lighter latent tails.

.. math::

   \eta=(\log\mu,\log\sigma,\nu,\log\tau),\quad f_{PE}(z)=\frac{\tau e^{-(|z|/\alpha)^\tau}}{2\alpha\Gamma(1/\tau)},\quad\alpha^2=\frac{\Gamma(1/\tau)}{\Gamma(3/\tau)}.

The response likelihood includes the transformation Jacobian and positive-support normalizer. Statistical fitting uses the existing joint solver with exact gradient and Hessian and fixed smoothing. Automatic smoothing is guarded. Varying shape need not admit a Hessian at y=mu, so that statistical surface is explicit. Neural fitting allows the first derivative there only for tau>1. Neural support-normalizer scores use checked vector CPU quadrature; higher autograd derivatives are unsupported. Mu need not equal the response mean, and existence-checked moments remain prediction operations.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Types, defaults and output shapes
---------------------------------

.. autoclass:: nampy.gam.families.gamlss.boxcox_tail.BCPELikelihood

Pass ``GAMLSS(family='bcpe_lss')``; this family has no constructor options.

``predict_parameters(X)`` returns natural parameters as a float ``(n,4)`` array, ``predict_link(X)`` returns link predictors ``(n,4)``, ``predict_point(X)`` returns the conditional mean ``(n,)``, and ``predict_components(X)`` returns an AdditivePrediction whose link and each term are ``(n,4)``. ``X`` is a DataFrame or numeric ``(n,d)`` array, consistent with formula mode.

Likelihood derivatives through order two are analytic, including mixed derivatives. Fixed smoothing is tested; automatic smoothing requires an enabled runtime capability and route-specific evidence. Residual availability follows the observation contract; ordinary response/Pearson residuals are unavailable for censored targets. Deviance residuals and null deviance are not defined by this implementation; use explicit response/Pearson diagnostics or shared distribution quantile residuals rather than the default deviance-residual plotting workflow.
