student_lss
===========

.. math::

   f(y)=\frac{\Gamma((\nu+1)/2)}{\Gamma(\nu/2)\sqrt{\nu\pi}\,\sigma}\left(1+\frac{(y-\mu)^2}{\nu\sigma^2}\right)^{-(\nu+1)/2}

* **Natural domains:** :math:`\mu\in\mathbb R,\ \sigma>0,\ 2<\nu<\infty`; fixed :math:`\nu=5` by default.
* **Conditional mean:** :math:`\mathbb E[Y\mid x]=\mu`
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=\sigma^2\nu/(\nu-2)`

:math:`Y=\mu+\sigma T_\nu,\quad T_\nu\sim t_\nu`

The gamlss.dist TF mapping uses the same location, t scale and degrees of freedom. Shared tail and likelihood theory is on :doc:`/statistical_reference/families/theory`.

Distribution reference: `gamlss.dist::TF <https://github.com/cran/gamlss.dist/blob/master/man/TF.Rd>`_. Fitting uses NAMpy's joint penalized engine, not gamlss RS backfitting. See :doc:`/development/neighbor_parity` for the tested mapping and numerical comparisons.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Types, defaults and output shapes
---------------------------------

.. autoclass:: nampy.gam.families.gamlss.distributional.StudentLocationScale

Pass ``{'name': 'student_lss', 'df': 5.0}`` to configure fixed degrees of freedom; df must be finite and >2.

``predict(X)`` returns natural parameters as a float ``(n,2)`` array, ``predict(X, raw=True)`` returns link predictors ``(n,2)``, ``predict_point(X)`` returns the conditional mean ``(n,)``, and ``predict_components(X)`` returns an AdditivePrediction whose link and each term are ``(n,2)``. ``X`` is a DataFrame or numeric ``(n,d)`` array, consistent with formula mode.

Likelihood derivatives through order four are analytic, including mixed derivatives. Fixed smoothing is tested; automatic smoothing requires an enabled runtime capability and route-specific evidence. Residual availability follows the observation contract; ordinary response/Pearson residuals are unavailable for censored targets. Deviance residuals and null deviance are not defined by this implementation; use explicit response/Pearson diagnostics or shared distribution quantile residuals rather than the default deviance-residual plotting workflow.
