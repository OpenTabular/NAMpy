ocat
====

.. math::

   \Pr(Y\leq j)=\operatorname{sigmoid}(c_j-\eta),\quad p_j=F(c_j-\eta)-F(c_{j-1}-\eta)

* **Natural domains:** :math:`\eta\in\mathbb R,\quad-\infty=c_{-1}<c_0<\cdots<c_{C-2}<c_{C-1}=\infty`
* **Conditional mean:** For integer-encoded labels, :math:`\mathbb E[Y\mid x]=\sum_{j=0}^{C-1}jp_j`; point prediction chooses a class.
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=\sum_{j=0}^{C-1}j^2p_j-\left(\sum_{j=0}^{C-1}jp_j\right)^2` for that encoding.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

An ordinal model uses ordered thresholds to partition a latent
location. A common predictor moves the cumulative probabilities
together, while ordered cutpoints prevent negative class probabilities.

.. math::

   P(Y\leq j)=F(c_j-\eta),\qquad P(Y=j)=F(c_j-\eta)-F(c_{j-1}-\eta).

F is logistic for the proportional-odds construction. Threshold
locations and an intercept are not independently identifiable without
the constructor's anchoring rule. A larger eta shifts probability
toward higher categories. This uses ordering without assuming equal
distances between labels; moments of integer encodings depend on the
chosen encoding. Class probabilities are often the most useful output.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Ordered categorical responses. Supply R (number of categories) or compatible theta cut-point information; identity is the latent-predictor link.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'ocat', 'R': 3})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``theta``
     - ``Sequence[float] | None``
     - ``None``
     - Cutpoint gap vector, length R-2. A supplied vector determines R=len(theta)+2; all positive gaps fix the cutpoints. Any negative gap requests estimation from log(abs(gaps)); zero/None uses estimated working gaps. Response labels must be integers 1..R, with R>=3.

     - ``int | None``
     - ``None``
     - Number of ordered response categories; required when category count cannot be inferred from supplied cut-point parameters.
   * - ``link``
     - ``str``

     - Link name or ordered sequence of links. Supported choices and interpretation are specific to this family; sequence order follows its linear predictors.
   * - ``eps``
     - ``float``
     - ``1e-09``
     - Positive numerical safeguard used in probability/domain clipping; this is not an additional distribution parameter.

The constructor returns a family object, not predictions. ``GAM.fit`` returns the fitted model. For a single-predictor family, ``GAM.predict(type='response')`` normally returns a response-scale array, while ``type='link'`` returns the additive predictor. Multi-predictor families have family-specific response transformations. ``GAMLSS.predict`` returns the family point summary; ``predict_parameters`` exposes natural parameters and ``predict_link`` exposes additive predictors. These interfaces can have different column meanings.
