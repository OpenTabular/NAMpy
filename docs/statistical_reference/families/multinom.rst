multinom
========

.. math::

   \Pr(Y=j)=p_j,\quad j\in\{0,\ldots,C-1\}

* **Natural domains:** :math:`p_j\geq0,\quad\sum_{j=0}^{C-1}p_j=1`
* **Conditional mean:** For the one-hot vector :math:`Z`, :math:`\mathbb E[Z\mid x]=p`; numeric label means depend on the encoding.
* **Conditional variance:** :math:`\operatorname{Cov}(Z\mid x)=\operatorname{diag}(p)-pp^{\mathsf T}` for one-hot :math:`Z`.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

A categorical model assigns probability to each unordered label.
Reference-category logits identify the statistical multinomial model
by fixing category zero's logit, removing an arbitrary common shift.

.. math::

   p_0=\frac{1}{1+\sum_{k=1}^{K}e^{\eta_k}},\qquad p_j=\frac{e^{\eta_j}}{1+\sum_{k=1}^{K}e^{\eta_k}},\qquad -\ell=-\log p_y.

Each eta_j is log odds relative to category zero, not an
independently fitted probability. All probabilities depend on all
logits through the shared denominator. A neural categorical head
instead supplies C logits and applies softmax; common logit shifts
leave probabilities unchanged. The class-label ordering controls
output columns and carries no numerical distance interpretation.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Multinomial logit regression against reference category zero, with K predictors and K+1 response probabilities.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'multinom'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

The constructor returns a family object, not predictions. ``GAM.fit`` returns the fitted model. For a single-predictor family, ``GAM.predict(type='response')`` normally returns a response-scale array, while ``type='link'`` returns the additive predictor. Multi-predictor families have family-specific response transformations. ``GAMLSS.predict`` returns the family point summary; ``predict_parameters`` exposes natural parameters and ``predict_link`` exposes additive predictors. These interfaces can have different column meanings.

Parameterization and interpretation
-----------------------------------


``multinom(K=1)`` uses ``K`` identity-linked log odds against reference class
zero, for categories ``0,...,K``. ``GAM`` response prediction and
``GAMLSS.predict`` return ``K+1`` probabilities, ordered ``p0,...,pK``.
``predict_point`` selects the first most-probable category. Raw/link prediction
has ``K`` columns, named ``eta1,...,etaK``. Additive components expand these
logits to ``K+1`` columns with a zero baseline column, so their contributions
and intercept reconstruct exactly. The probability Jacobian has shape
``(n, K+1, K)``.

Kernel references cover every packed derivative pattern through fourth order
at ``K=1,2,3,4``. Fixed-SP fits at ``K=1,2,3`` and a selected REML fit at
``K=2`` compare coefficients, covariance, EDF, score, predictions/SE and
deviance residuals. The latter are positive for a correct classification and
negative otherwise; other residual types are unavailable.

The source baseline dummy is one, adding one per class-zero observation to
its fitting log likelihood. At fourth derivative order its loop variable
also overwrites the returned scalar likelihood with ``K``. Both source
behaviors remain explicit in the likelihood contract. The public normalized
categorical log density uses actual probabilities. Source GAM probability SEs
clip cross-predictor covariance at zero; GAMLSS natural errors retain the full
covariance in the delta method. Example: ``examples/example_multinom_gam.py``.
