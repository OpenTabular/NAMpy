shash
=====

.. math::

   Z=\sinh\!\left[\delta\operatorname{asinh}\!\left(\frac{Y-\mu}{\sigma\delta}\right)-\epsilon\right]\sim\mathcal N(0,1)

* **Natural domains:** :math:`\mu,\epsilon\in\mathbb R,\quad\sigma,\delta>0`
* **Conditional mean:** :math:`\mathbb E[Y\mid x]=\mu+\sigma\delta\,\mathbb E\!\left[\sinh\!\left(\frac{\operatorname{asinh}Z+\epsilon}{\delta}\right)\right]`
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=(\sigma\delta)^2\operatorname{Var}\!\left[\sinh\!\left(\frac{\operatorname{asinh}Z+\epsilon}{\delta}\right)\right]`; finite for :math:`\delta>0`.

:math:`f_Y(y)=\varphi(z(y))|z'(y)|`

The public point prediction is the conditional median :math:`\mu+\sigma\delta\sinh(\epsilon/\delta)`; location :math:`\mu` is not generally the mean or median. The moments above use the mgcv scale reparameterization including the :math:`\delta` factor.

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

`Upstream shash parameterization <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/shash.html>`_.

The sinh-arcsinh law transforms a Gaussian latent variable to
control skewness and tail weight separately from location and scale.
In NAMpy's statistical parameterization, the delta scale factor is
part of the transformation.

.. math::

   Z=\sinh\!\left[\delta\,\operatorname{asinh}\!\left(\frac{Y-\mu}{\sigma\delta}\right)-\epsilon\right]\sim N(0,1).

The response density multiplies the Gaussian latent density by
the absolute Jacobian of this transformation. Epsilon changes
asymmetry; delta changes tail weight. At epsilon=0 and delta=1 the
law reduces to a Gaussian. With skewness present, mu is generally
neither the response mean nor its median; the documented point
prediction uses the transformed median. Parameter contributions
therefore need a parameter-specific interpretation.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Sinh-arcsinh distributional regression for location, scale, skewness and tail shape, using four predictors.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'shash'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Parameterization and interpretation
-----------------------------------


``shash(link=("identity", "logeb", "identity", "identity"), b=0.01,
phi_pen=0.001)`` models location, log scale, skewness and log tail shape.
These are the only supported links. ``sigma=exp(eta2)+b`` is bounded below by
positive ``b``. ``GAMLSS.predict`` returns ``(mu, sigma, epsilon, delta)``;
``predict_point`` is the source conditional median ``qf(0.5)``. Source quantile,
CDF/log-CDF and inverse-transform simulation hooks are present.
Source GAM response prediction returns ``(mu, log_sigma, epsilon, log_delta)``.

The fitting likelihood includes the source ridge
``-phi_pen * log(delta)**2`` (``phiPen`` is an accepted alias). Public normalized
density scoring omits that estimation ridge. All analytic derivatives through
fourth order are supplied. Fixed SP, Newton-selected REML and EFS references
cover initialization, covariance, criterion/EDF, AIC/logLik, predictions/SE,
residuals and summary tables.

The EFS parity captures provide the same explicit initial smoothing parameters
to both implementations. Source ``initial.spg`` uses the initially
reparameterized design with the original penalty coordinates: an arbitrary
eigenvector sign can change its starting parameters and the finite EFS
endpoint. Static source sign-transport checks record this dependence and
verify common-start prediction, covariance, penalty and EDF invariants.

Nonzero offsets are rejected. The source fitting likelihood's bin lookup
excludes a lower ``-Inf`` endpoint: an exactly zero standardized residual
therefore produces positive-infinite source likelihood. The normalized density
and residual expression stay finite there. Residual centering retains the
source epsilon-independent Bessel expression. Source residuals support
deviance and response types; no source null-deviance hook exists.
Example: ``examples/example_shash_gamlss.py``.
