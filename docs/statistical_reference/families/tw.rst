tw
==

Tweedie response with mass at zero and positive continuous values. Power is constrained between a and b, with 1 < a < b < 2. theta controls the power parameterization/estimation.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'tw'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Signature
---------

.. code-block:: python

   TweedieTwFamily(theta=None, link: str = 'log', a: float = 1.01, b: float = 1.99, eps: float = 1e-09)

Parameters
----------

Dimensions: ``n`` rows, ``d`` input columns, ``p`` fitted coefficients, ``q`` response/family output columns; ``n_ref`` is the centering-reference row count.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / input shape
     - Default
     - Description
   * - ``theta``
     - ``float | None``
     - ``None``
     - Natural Tweedie power convention: a positive theta in (a,b) fixes p=theta. Negative theta starts estimation at p=abs(theta); None/zero estimates power starting at the midpoint of (a,b). Internally, log((p-a)/(b-p)) is optimized.
   * - ``link``
     - ``str``
     - ``'log'``
     - Link name or ordered sequence of links. Supported choices and interpretation are specific to this family; sequence order follows its linear predictors.
   * - ``a``
     - ``float``
     - ``1.01``
     - Lower bound for the Tweedie variance power; used with b to constrain power strictly between one and two.
   * - ``b``
     - ``float``
     - ``1.99``
     - Family-specific lower bound or shape constraint. For gaulss it bounds standard deviation; for gammals/gumbls it bounds log scale; for shash it bounds scale.
   * - ``eps``
     - ``float``
     - ``1e-09``
     - Positive numerical safeguard used in probability/domain clipping; this is not an additional distribution parameter.

The constructor returns a family object, not predictions. ``GAM.fit`` returns the fitted model. For a single-predictor family, ``GAM.predict(type='response')`` normally returns a response-scale array, while ``type='link'`` returns the additive predictor. Multi-predictor families have family-specific response transformations. ``GAMLSS.predict`` exposes natural distribution parameters; ``predict(raw=True)`` exposes link predictors. These interfaces can have different column meanings.

Implementation notes
--------------------

Tweedie extended family (`mgcv::tw`) with estimated power parameter.

Upstream references:
- `mgcv/R/efam.r::tw` — family object (dev.resids, Dd, ls, aic, theta transform)
- `mgcv/R/gam.fit3.r::ldTweedie` — log density with derivatives
- `mgcv/src/misc.c::tweedious` — Dunn & Smyth (2005) series summation

The series summation mirrors the C `tweedious` routine term-for-term,
including the buffer-index bookkeeping that determines the scaling maximum
and the sweep boundaries, so summation order matches upstream.
