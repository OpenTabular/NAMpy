twlss
=====

.. math::

   Y=\sum_{j=1}^NZ_j,\quad N\sim\operatorname{Poisson}\!\left(\frac{\mu^{2-p}}{\phi(2-p)}\right)

* **Natural domains:** :math:`\mu>0,\quad\phi>0,\quad1<p<2`; power is fixed or modeled according to the family contract.
* **Conditional mean:** :math:`\mathbb E[Y\mid x]=\mu`
* **Conditional variance:** :math:`\operatorname{Var}(Y\mid x)=\phi\mu^p`

:math:`Z_j\sim\operatorname{Gamma}\!\left(\frac{2-p}{p-1},\ \mathrm{scale}=\phi(p-1)\mu^{p-1}\right)`

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

For power 1<p<2, a Tweedie response is a compound Poisson sum of
positive Gamma jumps. The event count can be zero, creating an exact
zero mass alongside a continuous positive density.

.. math::

   Y=\sum_{j=1}^{N}Z_j,\qquad N\sim\operatorname{Poisson}(\lambda_N),\quad P(Y=0)=e^{-\lambda_N},\quad \operatorname{Var}(Y)=\phi\mu^p.

The zero probability is coupled to mean, dispersion and power; it
is not an independent zero-inflation predictor. p controls the
mean-variance relationship, while phi controls its magnitude.
Estimating power can require numerical density-series evaluation.
Statistical tw can estimate a global power, twlss gives power and
dispersion their own predictors, and the neural interface fixes the
configured power. Their fitting routes are different even though
the compound-law interpretation is shared.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Tweedie mean, power and dispersion regression with three predictors. Smoothing selection uses EFS because higher analytic likelihood derivatives are unavailable.

Usage
-----

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'twlss'})

Pass this family instance or the equivalent name/options mapping as ``GAM(family=...)``. The factory returns independent mutable family state for each fit.

Parameterization and interpretation
-----------------------------------


``twlss(link=("log", "identity", "identity"), a=1.01, b=1.99)`` models
Tweedie mean, transformed power and log dispersion, with ``1 < a < b < 2``.
The mean link also accepts identity or square root; the remaining links are
identity. Source response values are ``(mu, theta, rho)``;
``GAMLSS.predict`` returns ``(mu, p, phi)``, where ``phi=exp(rho)`` and the
source logistic power map confines ``p`` to the supplied bounds.
``predict_point`` returns mean ``mu``.

Source ``available.derivs=0`` supplies the analytic likelihood gradient and
Hessian; third/fourth likelihood arrays and a numerical outer-derivative
fallback are unavailable. Smoothing selection automatically uses EFS,
including when another optimizer was requested. Fixed-SP and selected-EFS
fits have direct references for covariance, criterion/EDF, AIC/logLik,
predictions/SE, all three residual types and summary tables. The source null
fit retains its independent bounds ``a=1.001, b=1.999``; null postprocessing
uses each observation's fitted dispersion. Prior weights enter deviance
residuals and null deviance, although the fitting likelihood ignores them.

The source formula-list setup rejects an external fixed-SP vector when a
parametric-only middle predictor precedes another smooth. Equivalent source
captures fix the parameters inside their ``s(..., sp=...)`` terms. All three
predictor offsets, zero/positive responses, custom power bounds and both source
initialization branches have kernel references.
Selected-EFS parity uses the same explicit initial smoothing parameters in
both implementations. As for ``shash``, source ``initial.spg`` depends on
arbitrary initial penalty eigenvector signs; its uncontrolled finite EFS
endpoint need not agree across platforms. Common-start references compare
predicted functions, full prediction covariance, transported penalties, EDF
and criterion without fixing eigenvector orientation.
Example: ``examples/example_twlss_gamlss.py``.

Source for these six ports: mgcv 1.9-4 ``R/gamlss.r`` family constructors,
``pen.reg``, ``gamlss.etamu``, ``gamlss.gH`` and ``gam.fit5``; Tweedie uses
``R/gam.fit3.r::ldTweedie`` and ``R/gamlss.r::tw.null.fit``. Cross-platform CI
and merge acceptance are tracked separately from these local reference scopes.
