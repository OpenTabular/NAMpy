weibull_observation_lss
=======================

.. math::

   f_T(y)=\frac{f(y)}{Z}\mathbf1(L<y<U),\quad Z=F(U)-F(L)

* **Natural domains:** Scale :math:`\lambda>0`; shape :math:`k>0`.; fixed truncation satisfies 0<=L<U; infinite upper bounds are supported.
* **Conditional mean:** :math:`E_T[Y]=\frac{1}{Z}\int_L^U y f(y)\,dy`; the estimator's default point summary is the conditional median. This integral defines the mean mathematically; generic conditional mean evaluation is unsupported.
* **Conditional variance:** :math:`\operatorname{Var}_T(Y)=\frac{1}{Z}\int_L^U y^2 f(y)\,dy-E_T[Y]^2`; generic conditional variance evaluation is unsupported.

latent law: :math:`f(y)=\frac{k}{\lambda}(y/\lambda)^{k-1}e^{-(y/\lambda)^k},\quad y>0`. Exact observations contribute log density; censored intervals contribute log interval probability, each minus log Z

References: `mgcv distribution-family definitions <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/family.mgcv.html>`_. NAMpy fitting support is listed below.

Explicit observation targets compose positive Weibull scale and shape with exact, left/right-censored and interval observations and optional fixed truncation. The natural parameters describe the latent law.

.. math::

   Z=F(U)-F(L),\quad\ell=\log f(y)-\log Z\text{ (exact)},\quad\ell=\log\{F(b)-F(a)\}-\log Z\text{ (censored)}.

Truncation conditions the prediction law; censoring records which interval was observed. ObservationTarget is separate from weights and predictors. Statistical likelihood derivatives through order four support fixed and validated Newton/BFGS REML fitting; neural losses are differentiable. The default point summary is the conditional median. Generic conditional means and variances are unsupported for these laws. Variable truncation bounds and discrete/mixed compositions are unsupported.

See :doc:`/statistical_reference/families/theory` for likelihoods,
links, weights and distributional predictors. The mathematical law
does not imply support for every fitting or smoothing-selection route;
the contracts below define the implemented combinations.

Target encoding, response/link column meanings and supported fitting criteria are specified in the tables and examples below. Scalar uncensored targets have shape ``(n,)``. Residual choices are family-specific; use :doc:`/statistical_reference/methods/residuals`. Log likelihood is higher-is-better; AIC/BIC are lower-is-better and require a normalized comparable likelihood.

Implementation definitions: :mod:`nampy.gam.families`. See the source link on the runtime contract for the implemented transforms and objective.

Types, defaults and output shapes
---------------------------------

.. autoclass:: nampy.gam.families.gamlss.observations.WeibullObservations

Use family={'name': 'weibull_observation_lss', 'lower': L, 'upper': U} for fixed truncation and supply ObservationTarget to fit. Defaults leave both tails untruncated.

``predict_parameters(X)`` returns natural parameters as a float ``(n,2)`` array, ``predict_link(X)`` returns link predictors ``(n,2)``, ``predict_point(X)`` returns the conditional median ``(n,)``, and ``predict_components(X)`` returns an AdditivePrediction whose link and each term are ``(n,2)``. ``X`` is a DataFrame or numeric ``(n,d)`` array, consistent with formula mode.

Likelihood derivatives through order four are analytic, including mixed derivatives. Fixed smoothing is tested; automatic smoothing requires an enabled runtime capability and route-specific evidence. Residual availability follows the observation contract; ordinary response/Pearson residuals are unavailable for censored targets. Deviance residuals and null deviance are not defined by this implementation; use explicit response/Pearson diagnostics or shared distribution quantile residuals rather than the default deviance-residual plotting workflow.
