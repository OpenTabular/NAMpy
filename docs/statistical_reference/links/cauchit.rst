Cauchit link
============

.. math::

   g(p)=\tan\{\pi(p-\tfrac12)\},\qquad g^{-1}(\eta)=\tfrac12+\frac{\arctan\eta}{\pi}

* **Domains:** :math:`0<p<1,\quad\eta\in\mathbb R`. The response family can impose stricter restrictions.
* **Inverse derivative:** :math:`dp/d\eta=\frac1{\pi(1+\eta^2)}`.

A Cauchy latent threshold gives probabilities with heavier predictor tails than a probit link. This changes the response to extreme predictor values; it does not make the binary response a Student-t distribution.

Forward evaluation uses stable cotangent/complement forms. The inverse limits predictor magnitude using the machine-epsilon tail quantile, and the inverse derivative has a positive floor.

Configure the family
--------------------

.. code-block:: python

   from nampy.gam.families.registry import make_gam_family

   family = make_gam_family({'name': 'binomial', 'link': 'cauchit'})
   # Pass this instance, or its options mapping, to GAM(family=...).

The family factory has signature ``make_gam_family(family)``. Its required argument accepts a family name, options mapping, family instance (cloned), or ``None`` (Gaussian identity); it returns one independent family object. The mapping's ``name`` and ``link`` are strings. Unsupported family/link pairs raise ``ValueError``. The numerical link classes are implementation objects obtained through a family, rather than a second public factory.

Single-predictor family factories using this named link: :doc:`binomial <../families/binomial>`, :doc:`quasi <../families/quasi>`, :doc:`quasipoisson <../families/quasipoisson>`, :doc:`quasibinomial <../families/quasibinomial>`, :doc:`betar <../families/betar>`. This describes link selection, not every family/design/optimizer combination. Specialized distributional links retain their family-specific parameterization.

Evaluation signatures and inputs
--------------------------------

.. code-block:: python

   family.link(mu)
   family.inverse_link(eta)
   family.mu_eta(eta)
   family.d2link(mu)
   family.d3link(mu)
   family.d4link(mu)

``mu`` — Type: array-like of floats, shape ``S`` (scalar ``()`` permitted)
   Default: ``required``. Response means/probabilities in the displayed link domain. Convert input to a numeric array; the forward link does not generally repair invalid domains.

``eta`` — Type: array-like of floats, shape ``S`` (scalar ``()`` permitted)
   Default: ``required``. Additive predictors in the inverse-link domain. ``inverse_link`` and ``mu_eta`` consume eta, not response means.

Outputs
-------

``family.link(mu)`` — Type: floating NumPy array/scalar-shaped numerical result, shape ``S``
   Forward predictor values. An existing float64 input can be returned without copying for identity.

``family.inverse_link(eta)`` — Type: floating NumPy array/scalar-shaped numerical result, shape ``S``
   Response mean/probability after the numerical safeguards described above; no response noise is added.

``family.mu_eta(eta)`` — Type: floating numerical result, shape ``S``
   Derivative of the inverse link, d mu / d eta. It can be negative for decreasing links.

``family.d2link(mu), d3link(mu), d4link(mu)`` — Type: floating numerical results, shape ``S``
   Second, third and fourth derivatives of the forward link with respect to mu, used by fitting derivatives. These are not derivatives of predictions with respect to a source feature.

Ordinary Python lists are accepted through NumPy conversion. Scalar inputs retain shape ``()``; concrete scalar container types can differ between link operations. These elementwise methods preserve broadcasting shape and do not check model convergence.

Link definitions follow `R's GLM link conventions <https://stat.ethz.ch/R-manual/R-devel/library/stats/html/make.link.html>`_; numerical behavior and accepted factory combinations above are taken from NAMpy.
