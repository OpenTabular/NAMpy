Link functions
==============

A response law and a link are separate choices. The link connects a conditional parameter to an additive predictor; its inverse maps back to that parameter's domain. Each page gives the formula, domains, numerical safeguards, factory configuration, evaluation signatures and a runnable example.

Which derivative?
-----------------

``mu_eta(eta)`` differentiates the inverse link. ``d2link(mu)`` through ``d4link(mu)`` differentiate the forward link. Numerical family fitting uses these derivatives with the basis design; they are separate from ``GAM.derivative``, which differentiates a fitted term with respect to its covariate.

Changing the link changes effect interpretation, not the response support or variance function. In particular, quasi ``power`` configures a link exponent, while ``variance`` selects the mean-variance relationship. Families with several predictors also have specialized links described on their :doc:`family pages <../families/index>`.

Family factory
--------------

Signature
~~~~~~~~~

.. code-block:: python

   make_gam_family(family)

Parameters
~~~~~~~~~~

``family`` — Type: str | mapping[str, object] | BaseFamily | None
   Default: ``required (None selects Gaussian identity)``. A name uses that family's default link. A mapping selects name and supported options such as link. An existing family is independently cloned. Unsupported names/options or links raise errors according to the chosen factory; custom R closures are not accepted.

Outputs
~~~~~~~

``return value`` — Type: BaseFamily subclass instance, scalar object
   Unfitted, independent response-family state. It supplies link, inverse_link, mu_eta and forward-link derivatives where applicable; it does not contain fitted regression predictions.
