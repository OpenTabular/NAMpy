Basis and penalty construction
==============================

The compiler consumes these options before coefficient fitting. Linked terms must have compatible basis setup; changing penalty scaling changes the smoothing-parameter coordinates.

Create one validated ``GAMControl`` with ``gam_control(...)`` and pass it as ``control=``. Unknown keys raise ``TypeError``; invalid values raise ``ValueError`` except the documented reset policies.

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Setting
     - Type / default
     - Valid values
     - Effect
   * - .. _control-id-links-bases:

       ``id_links_bases``
     - ``bool``, ``True``
     - True or False
     - Share compatible basis setup for terms linked by a smoothing identifier.
   * - .. _control-scale-penalty:

       ``scale_penalty``
     - ``bool``, ``True``
     - True or False
     - Rescale supported penalty matrices for numerical fitting stability.

Accepted aliases: ``idLinksBases`` → ``id_links_bases``, ``scalePenalty`` → ``scale_penalty``.
