P-ML
====

Pearson-scale variant of maximum likelihood selection. Known-scale families normalize to ML; extended families normalize to REML.

Theory and interpretation
-------------------------

The Pearson-scale ML variant changes how an unknown dispersion is
supplied to a marginal-likelihood criterion. It uses Pearson residual
information rather than claiming a new likelihood family.

.. math::

   \widehat\phi_P=\frac{\sum_i w_i(y_i-\widehat\mu_i)^2/V(\widehat\mu_i)}{n-\mathrm{EDF}}.

This displays the usual Pearson-scale interpretation; the
implemented criterion retains its route's rank, observation and
nuisance-parameter conventions. Known-scale families normalize p-ml
to ML. Extended families normalize this spelling to REML in NAMpy,
so the name alone does not establish a distinct fitted objective.

See :doc:`/statistical_reference/selection/theory` for the full
coefficient/selection loop, notation and comparison rules. The
configuration and support contracts below describe NAMpy's routes.

Configuration
-------------

.. code-block:: python

   from nampy.models import GAMRegressor

   model = GAMRegressor(optimize_smoothing=True, smoothing_method='p-ml')
   # model.fit(X_train, y_train)

Outputs and restrictions
------------------------

``fit`` returns the estimator. Its ``gam_`` records the fitted coefficients and smoothing parameters. ``predict`` returns response predictions. The chosen criterion and outer optimizer are separate choices; a named criterion does not establish support for every family, tensor or coefficient transform. Consult the :doc:`fitting support matrix </api/gam_advanced>` and :doc:`compatibility boundaries </compatibility>`.
