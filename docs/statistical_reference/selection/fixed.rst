FIXED
=====

Fit coefficients at configured penalty strengths without selecting smoothing parameters. Set optimize_smoothing=False; smoothing_params controls the penalty values.

Theory and interpretation
-------------------------

Fixed smoothing solves the coefficient problem at the supplied
penalty strengths. There is no data-driven outer choice of lambda.
This is useful for scientifically chosen regularization or for
comparing externally selected penalty settings.

.. math::

   \widehat\beta_\lambda=\arg\min_\beta\{-\ell(\beta)+\tfrac12\beta^\mathsf TS_\lambda\beta\},\qquad S_\lambda=\sum_j\lambda_jS_j.

Fixed lambda does not mean fixed coefficients, and it does not
mean an unpenalized fit. Lambda=0 removes a particular penalty, while
a positive value retains shrinkage. Penalty rescaling and weights
determine the numerical meaning of a supplied lambda, so values
cannot be transferred blindly between unrelated basis setups.

See :doc:`/statistical_reference/selection/theory` for the full
coefficient/selection loop, notation and comparison rules. The
configuration and support contracts below describe NAMpy's routes.

Configuration
-------------

.. code-block:: python

   from nampy.models import GAMRegressor

   model = GAMRegressor(optimize_smoothing=False, smoothing_method='fixed')
   # model.fit(X_train, y_train)

Outputs and restrictions
------------------------

``fit`` returns the estimator. Its ``gam_`` records the fitted coefficients and smoothing parameters. ``predict`` returns response predictions. The chosen criterion and outer optimizer are separate choices; a named criterion does not establish support for every family, tensor or coefficient transform. Consult the :doc:`fitting support matrix </api/gam_advanced>` and :doc:`compatibility boundaries </compatibility>`.
