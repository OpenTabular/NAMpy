NCV
===

Neighborhood cross-validation: approximate deletion of specified observation neighborhoods followed by prediction at specified held-out rows.

Theory and interpretation
-------------------------

Neighborhood cross-validation removes specified observation
sets, then evaluates prediction loss at associated held-out rows.
Deletion sets and prediction sets need not be the same, which can
represent local dependence or observation clusters.

.. math::

   \operatorname{NCV}(\lambda)=\sum_k\sum_{i\in P_k}d\{y_i,\widehat\mu_i^{(-D_k)}(\lambda)\}.

D_k is a deletion neighborhood and P_k its prediction rows.
NAMpy approximates the coefficient change using the fitted
likelihood's derivative/curvature information instead of fully
refitting every deletion. A neighborhood should reflect the intended
prediction problem; ordinary leave-one-row-out can be optimistic
when nearby rows share information. The nei contract specifies
indexing and membership; ncv_threads does not enable parallel kernels.

See :doc:`/statistical_reference/selection/theory` for the full
coefficient/selection loop, notation and comparison rules. The
configuration and support contracts below describe NAMpy's routes.

Configuration
-------------

.. code-block:: python

   from nampy.models import GAMRegressor

   model = GAMRegressor(optimize_smoothing=True, smoothing_method='ncv')
   # model.fit(X_train, y_train)

   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / shape
     - Default
     - Meaning
   * - smoothing_method
     - str
     - fixed on GAM; reml on estimator wrappers
     - Neighborhood cross-validation: approximate deletion of specified observation neighborhoods followed by prediction at specified held-out rows.
   * - optimize_smoothing
     - bool
     - False on GAM; True on wrappers

   * - smoothing_params

     - None
     - Penalty strengths or supported initialization. Fixed/estimated conventions follow the selected fitting route.
   * - control
     - GAMControl | Mapping | None

Outputs and restrictions
------------------------

``fit`` returns the estimator. Its ``gam_`` records the fitted coefficients and smoothing parameters. ``predict`` returns response predictions. The chosen criterion and outer optimizer are separate choices; a named criterion does not establish support for every family, tensor or coefficient transform. Consult the :doc:`fitting support matrix </api/gam_advanced>` and :doc:`compatibility boundaries </compatibility>`.
