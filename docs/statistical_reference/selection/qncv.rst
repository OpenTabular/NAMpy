QNCV
====

Quadratic neighborhood cross-validation: a quadratic expansion of the held-out deviance criterion, using the same neighborhood structure as NCV.

Theory and interpretation
-------------------------

Quadratic NCV retains the same neighborhood deletion structure
but approximates the held-out loss itself by a second-order expansion
around the full-data fit.

.. math::

   d(\widehat\eta+\Delta\eta)\approx d(\widehat\eta)+\nabla d^\mathsf T\Delta\eta+\tfrac12\Delta\eta^\mathsf T\nabla^2d\,\Delta\eta.

Thus both coefficient deletion and loss evaluation use local
information. Accuracy depends on the size of the deletion-induced
change and the quality of the local curvature approximation. QNCV
does not make neighborhoods independent or replace the need for
genuinely held-out validation. Compare it with NCV using the same
neighborhood definition and response-loss convention.

See :doc:`/statistical_reference/selection/theory` for the full
coefficient/selection loop, notation and comparison rules. The
configuration and support contracts below describe NAMpy's routes.

Configuration
-------------

.. code-block:: python

   from nampy.models import GAMRegressor

   model = GAMRegressor(optimize_smoothing=True, smoothing_method='qncv')
   # model.fit(X_train, y_train)

   :header-rows: 1

   * - Parameter
     - Type / shape
     - Default
     - Meaning
   * - smoothing_method
     - str
     - fixed on GAM; reml on estimator wrappers
     - Quadratic neighborhood cross-validation: a quadratic expansion of the held-out deviance criterion, using the same neighborhood structure as NCV.
   * - optimize_smoothing
     - bool
     - False on GAM; True on wrappers
     - Enable criterion/optimizer updates. False fits at configured penalty strengths.

     - Penalty strengths or supported initialization. Fixed/estimated conventions follow the selected fitting route.
   * - control
     - GAMControl | Mapping | None

     - Validated nested solver settings; None resolves through gam_control().

Outputs and restrictions
------------------------

``fit`` returns the estimator. Its ``gam_`` records the fitted coefficients and smoothing parameters. ``predict`` returns response predictions. The chosen criterion and outer optimizer are separate choices; a named criterion does not establish support for every family, tensor or coefficient transform. Consult the :doc:`fitting support matrix </api/gam_advanced>` and :doc:`compatibility boundaries </compatibility>`.
