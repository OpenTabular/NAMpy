ML
==

Maximum marginal likelihood smoothing selection with the supported Gaussian or Laplace/general-family backend.

Theory and interpretation
-------------------------

The random-effects interpretation treats penalized coefficient
directions as Gaussian latent effects. Marginal maximum likelihood
integrates those directions out and estimates their variance, leaving
unpenalized coefficients as fixed effects.

.. math::

   L_M(\lambda,\phi,\alpha)=\int p(y\mid\alpha,b,\phi)\,p(b\mid\lambda,\phi)\,db.

The Gaussian integral is exact for compatible Gaussian designs;
non-Gaussian models use a supported Laplace approximation. The
integration automatically trades fit against the volume of plausible
coefficient values. Unlike ordinary coefficient maximum likelihood,
this selects smoothing strengths. Comparing models with different
unpenalized fixed-effect spaces generally calls for ML rather than
comparing their REML scores.

See :doc:`/statistical_reference/selection/theory` for the full
coefficient/selection loop, notation and comparison rules. The
configuration and support contracts below describe NAMpy's routes.

Configuration
-------------

.. code-block:: python

   from nampy.models import GAMRegressor

   model = GAMRegressor(optimize_smoothing=True, smoothing_method='ml')
   # model.fit(X_train, y_train)

.. list-table::
   :header-rows: 1
   :class: api-reference-table

   * - Parameter
     - Type / shape
     - Default
     - Meaning
   * - smoothing_method
     - str
     - fixed on GAM; reml on estimator wrappers
     - Maximum marginal likelihood smoothing selection with the supported Gaussian or Laplace/general-family backend.
   * - optimize_smoothing
     - bool
     - False on GAM; True on wrappers
     - Enable criterion/optimizer updates. False fits at configured penalty strengths.
   * - smoothing_params
     - float | array-like (n_penalties,) | None
     - None
     - Penalty strengths or supported initialization. Fixed/estimated conventions follow the selected fitting route.
   * - control
     - GAMControl | Mapping | None
     - None
     - Validated nested solver settings; None resolves through gam_control().

     - Fitted object itself.
   * - smoothing_params
     - numpy.ndarray[float64]
     - (n_penalties,)
     - Available on the core GAM, or ``estimator.gam_``.
   * - predict
     - numpy.ndarray[float]
     - (n,) for this Gaussian example
     - Response mean prediction; other families follow their own output contract.

Outputs and restrictions
------------------------

``fit`` returns the estimator. Its ``gam_`` records the fitted coefficients and smoothing parameters. ``predict`` returns response predictions. The chosen criterion and outer optimizer are separate choices; a named criterion does not establish support for every family, tensor or coefficient transform. Consult the :doc:`fitting support matrix </api/gam_advanced>` and :doc:`compatibility boundaries </compatibility>`.
