Reference
=========

Each feature has one canonical description. Start with a model interface, then
look up its predictions, probability laws, or the extension interfaces used to
implement a feature.

* :doc:`Statistical models </statistical_reference/index>`: estimators, formulas, smooths, families, fitting and inference.
* :doc:`Neural models </neural_reference/index>`: architectures, estimators, response distributions and training.
* :doc:`Predictions and explanations <contracts>`: shared result objects, explanation helpers, and diagnostic records.
* :doc:`Probability laws <distributions>`: backend-neutral distribution objects and their probability operations.
* :doc:`Plotting <plotting>`: plotting inputs, outputs and rendering options.
* :doc:`Calibration <calibration>`: post-fit conformal scores, grouped scores, and survival bounds.
* :doc:`Extension APIs </extension_reference/index>`: runtime terms, registries and custom implementations.
* :doc:`Bibliography </references>`: papers and methodological books, with the scope covered by each one.
* :doc:`Survival prediction and uncertainty <survival>`: shared targets, curves, metrics and intervals.
