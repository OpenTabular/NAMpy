Outputs
-------

``fit(X, feature_names)`` accepts a numeric/categorical design with n rows and its d column names, initializes the term, and returns the same term instance. ``transform_new(X_new)`` returns a floating NumPy array of shape (n_new, p_term) in the fitted constraint coordinates. ``penalties`` is a list of floating square arrays, each (p_term, p_term). Multiplying the design by its coefficient vector gives the link contribution of shape (n_new,). Invalid feature names, dimensions and basis-specific domains raise ValueError; unsupported compositions raise NotImplementedError.

Implementation notes
--------------------

Cubic regression spline smooth term (``bs='cr'``).

Implements the :class:`BaseSmoothTerm` interface for a single-variable cubic
regression spline basis with a second-derivative penalty.  Knots are either
user-supplied or chosen automatically using quantiles of the training data.

An optional null-space selection penalty is added when ``select=True``,
allowing the term to be shrunk to zero.

A point constraint ``f(x0) = 0`` may be specified via ``pc=x0``. The basis
is reparameterized so its evaluated row at that location is zero. This is a
constraint on the fitted function, not generally on one arbitrary coefficient.
