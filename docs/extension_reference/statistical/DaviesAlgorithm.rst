DaviesAlgorithm
===============

.. math::

   F_Q(q)=\frac12-\frac1\pi\int_0^\infty\frac{\operatorname{Im}\{e^{-itq}\varphi_Q(t)\}}{t}\,dt

For a nondegenerate continuous quadratic-form law, characteristic-function inversion gives its CDF. Davies chooses integration/truncation parameters using error bounds for the weighted independent chi-square components and optional independent normal term. This is numerical probability evaluation, not simulation or model fitting.

The integration method returns the lower tail plus diagnostic trace and a fault code; it has no automatic Liu fallback. Use :doc:`psum_chisq` for the convenience wrapper, or this class when raw numerical diagnostics are required. The Python integration port is sequential; reuse of one mutable integration object across concurrent calls is not an advertised interface.

Check both probability range and fault code. Failed paths can return a negative probability sentinel, including an early auxiliary-budget exit whose code can still be zero. Degenerate all-zero components with zero Gaussian term use the implementation's strict comparison at zero. Use nondegenerate inputs for the usual continuous-law CDF interpretation. The implementation follows `mgcv's Davies source <https://github.com/cran/mgcv/blob/master/src/davies.c>`_.

Import: ``from nampy.gam.inference.chi_square_mixtures import DaviesAlgorithm``. These are backend helper APIs; core-model methods remain the usual analysis interface.

Integration method
------------------

Signature
~~~~~~~~~

.. code-block:: python

   solver.davies(lb, nc, n, r, sigma, c_val, lim, acc)

Parameters
~~~~~~~~~~

``lb`` — Type: array-like[float], length r
   Default: ``required``. Weights of the chi-square terms; signed weights are permitted.

``nc`` — Type: array-like[float], length r
   Default: ``required``. Finite nonnegative noncentralities, with no implicit scalar repetition at this low level.

``n`` — Type: array-like[int], length r
   Default: ``required``. Nonnegative integer degrees of freedom. The method casts to integer dtype; supply integers rather than relying on truncation.

``r`` — Type: int > 0
   Default: ``required``. Number of chi-square components, matching all three array lengths.

``sigma`` — Type: float >= 0
   Default: ``required``. Standard-normal multiplier, not its variance.

``c_val`` — Type: float
   Default: ``required``. One threshold q; call separately for several thresholds.

``lim`` — Type: int > 0
   Default: ``required``. Integration-term budget, corresponding to nlim on the wrapper.

``acc`` — Type: float > 0
   Default: ``required``. Requested numerical probability accuracy, corresponding to tol on the wrapper.

Outputs
~~~~~~~

``probability`` — Type: float, shape ()
   Lower-tail probability on a successful evaluation; negative sentinels are possible on failed paths.

``trace`` — Type: list[float], length 7
   Zero-based entries: [0] absolute-value sum/error diagnostic; [1] total integration terms; [2] number of integrations; [3] main integration interval; [4] initial truncation point; [5] convergence-factor SD; [6] parameter-search cycle count. Failed paths can contain partial/zero entries.

``ifault`` — Type: int, shape ()
   Local return codes: 0 nominal completion, 1 insufficient integration budget/accuracy, 2 possible round-off error, 3 invalid component parameters. Also check probability range as explained above. These values are numerical diagnostics, not hypothesis-test outcomes.
