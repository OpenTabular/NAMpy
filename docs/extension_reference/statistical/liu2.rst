liu2
====

.. math::

   c_k=\sum_jh_j\lambda_j^k,\qquad\kappa_k(Q)=2^{k-1}(k-1)!\,c_k\quad(\text{central components})

Liu's approximation matches standardized moments of a central weighted quadratic form to a scaled noncentral chi-square reference. Here c1 is its mean, 2*c2 its variance, and c3/c2**1.5 and c4/c2**2 determine the skewness/kurtosis matching branch. A scaled chi-square with one common positive weight is a useful exact-reference check.

This helper accepts central components only: it has no noncentrality or Gaussian-noise argument. It is an approximation for the intended nonnegative-definite form, not Davies integration for arbitrary signed weights. The routine checks vector lengths but does not comprehensively validate all mathematical preconditions.

**Boundary convention:** thresholds at or below zero retain an initialized value of 1 for either tail setting. Degenerate nonpositive second-moment sums also return 1. For a nonnegative quadratic form, this agrees with the usual upper tail at negative thresholds, but it is not the mathematical lower-tail CDF. The selected chi-square CDF/SF is applied only to positive thresholds.

The higher-order matching follows the Liu, Tang and Zhang approximation cited by `mgcv psum.chisq <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/psum.chisq.html>`_. Inspect approximation quality rather than treating it as an exact test distribution.

Import: ``from nampy.gam.inference.chi_square_mixtures import liu2``. These are backend helper APIs; core-model methods remain the usual analysis interface.

Signature
---------

.. code-block:: python

   liu2(x: 'float | np.ndarray', lb: 'np.ndarray', *, df: 'np.ndarray | None' = None, lower_tail: 'bool' = False) -> 'float | np.ndarray'

Parameters
----------

``x`` — Type: float | one-dimensional array-like[float], shape () or (n,)
   Default: ``required``. Threshold(s) at which the tail probability is evaluated. Use scalar or 1D input; arbitrary multi-axis input is not supported by the Davies wrapper.

``lb`` — Type: array-like[float], flattened shape (r,)
   Default: ``required``. Weights of independent chi-square variables. Davies supports signed weights; at least one nonzero weight is required. For the intended Liu approximation use nonnegative weights with at least one positive entry.

``df`` — Type: array-like[float] | None, scalar/length 1 or (r,)
   Default: ``None``. Degrees of freedom, default ones. A single value is repeated. psum_chisq rounds with NumPy rint and requires positive integer results; liu2 uses supplied real values directly and only checks matching lengths. Supply positive degrees of freedom.

``lower_tail`` — Type: bool
   Default: ``False``. False requests the upper-tail moment approximation; True requests its CDF for positive thresholds. Nonpositive-threshold behavior is noted below.

Outputs
-------

``return value`` — Type: float for scalar input; numpy.ndarray[float64] of shape (n,) for vector input
   Tail probability/approximation in input threshold order. The wrapper can return NaN when numerical evaluation fails. No trace attributes are attached; use DaviesAlgorithm.davies for raw integration diagnostics. See the numerical/fallback behavior below before interpreting a returned value.
