psum_chisq
==========

.. math::

   Q=\sum_{j=1}^{r}\lambda_jX_j+\sigma_zZ,\qquad X_j\sim\chi^2_{h_j}(\delta_j),\quad Z\sim N(0,1)

The components are independent. Weighted chi-square sums arise when a Gaussian quadratic-form statistic is diagonalized: covariance/design geometry determines the weights, rather than an arbitrary integer EDF. Signed weights and an independent Gaussian term are allowed by the Davies calculation. By default this function returns the upper tail, the convention commonly needed for a p-value.

Davies evaluates a characteristic-function inversion with an accuracy target and an integration budget. On a normal successful path ``lower_tail=True`` returns the CDF. Status 2 emits a round-off warning while retaining the computed probability. Other failed central cases warn and invoke Liu; failed noncentral cases return NaN.

**Current fallback convention:** the wrapper calls ``liu2`` with its default upper tail even when ``lower_tail=True``. That fallback uses only weights and degrees of freedom, omitting ``sigz``. Use ``liu2(..., lower_tail=True)`` explicitly when a lower-tail central approximation is intended. Do not infer a successful exact evaluation from the absence of an exception or ignore warnings; this port does not attach trace/status attributes to its returned probabilities.

The calibration of a GAM term statistic additionally depends on the fitted covariance, rank and smoothing assumptions. A numerical tail probability alone does not establish an exact finite-sample hypothesis test. See :doc:`/statistical_reference/inference` and `mgcv psum.chisq <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/psum.chisq.html>`_.

Import: ``from nampy.gam.inference.chi_square_mixtures import psum_chisq``. These are backend helper APIs; core-model methods remain the usual analysis interface.

Signature
---------

.. code-block:: python

   psum_chisq(q: 'float | np.ndarray', lb: 'np.ndarray', *, df: 'np.ndarray | None' = None, nc: 'np.ndarray | None' = None, sigz: 'float' = 0.0, lower_tail: 'bool' = False, tol: 'float' = 2e-05, nlim: 'int' = 100000) -> 'float | np.ndarray'

Parameters
----------

``q`` — Type: float | one-dimensional array-like[float], shape () or (n,)
   Default: ``required``. Threshold(s) at which the tail probability is evaluated. Use scalar or 1D input; arbitrary multi-axis input is not supported by the Davies wrapper.

``lb`` — Type: array-like[float], flattened shape (r,)
   Default: ``required``. Weights of independent chi-square variables. Davies supports signed weights; at least one nonzero weight is required. For the intended Liu approximation use nonnegative weights with at least one positive entry.

``df`` — Type: array-like[float] | None, scalar/length 1 or (r,)
   Default: ``None``. Degrees of freedom, default ones. A single value is repeated. psum_chisq rounds with NumPy rint and requires positive integer results; liu2 uses supplied real values directly and only checks matching lengths. Supply positive degrees of freedom.

``nc`` — Type: array-like[float] | None, scalar/length 1 or (r,)
   Default: ``None``. Noncentralities, default zeros; a single value is repeated. Supply finite nonnegative values. Mismatched vector lengths raise ValueError.

``sigz`` — Type: float
   Default: ``0.0``. Multiplier of an independent standard normal term. Nonpositive values are treated as zero.

``lower_tail`` — Type: bool
   Default: ``False``. False requests the upper tail; True requests the CDF on a successful Davies evaluation. Read the fallback qualification below.

``tol`` — Type: float > 0
   Default: ``2e-5``. Requested numerical integration accuracy; not a statistical confidence level.

``nlim`` — Type: int > 0
   Default: ``100000``. Maximum integration-term budget passed to Davies.

Outputs
-------

``return value`` — Type: float for scalar input; numpy.ndarray[float64] of shape (n,) for vector input
   Tail probability/approximation in input threshold order. The wrapper can return NaN when numerical evaluation fails. No trace attributes are attached; use DaviesAlgorithm.davies for raw integration diagnostics. See the numerical/fallback behavior below before interpreting a returned value.
