exclude_too_far
===============

.. math::

   \mathrm{exclude}_i=\mathbf1\left\{\min_j\left\|\widetilde g_i-\widetilde d_j\right\|_2>\mathrm{dist}\right\}

Prediction over a rectangle can include locations far outside observed support. This helper makes a geometric mask by scaling each grid axis to [0,1], applying those same shifts/scales to observations, and comparing each grid node's nearest observed distance with a radius. Thus changing axis units does not change the mask under a consistent positive linear rescaling.

The scaling comes from the grid range, not the observed range. Equality at the radius is retained. A True entry means exclude it; it is not a keep mask. This does not compute a convex hull, density threshold or uncertainty interval, and it does not change fitted coefficients. A nondegenerate finite grid and nonempty observations are prerequisites. The implementation forms pairwise distances, so memory grows with grid size times data size.

See `mgcv exclude.too.far <https://stat.ethz.ch/R-manual/R-devel/library/mgcv/html/exclude.too.far.html>`_ for the geometric convention. ``plot``/``vis`` expose related masking options; this page documents direct mask construction.

Import: ``from nampy.gam.diagnostics.plots import exclude_too_far``. These are backend helper APIs; core-model methods remain the usual analysis interface.

Signature
---------

.. code-block:: python

   exclude_too_far(g1, g2, d1, d2, dist)

Parameters
----------

``g1; g2`` — Type: array-like[float], each flattened to (n_grid,)
   Default: ``required``. Paired grid coordinates. Lengths must agree; each grid axis must have finite nonzero range for the normalization to be defined.

``d1; d2`` — Type: array-like[float], each flattened to (n_data,)
   Default: ``required``. Paired observed coordinates; equal lengths and at least one finite observed point. They are normalized using grid bounds, not their own bounds.

``dist`` — Type: float >= 0
   Default: ``required``. Euclidean exclusion radius after scaling the grid axes to [0,1]. It is dimensionless, not a raw distance in either input unit.

Outputs
-------

``return value`` — Type: numpy.ndarray[bool], shape (n_grid,)
   True marks a grid point whose nearest observed point is strictly farther than dist. False retains it. Reshape explicitly to a mesh shape if needed. Inputs are copied; unequal paired lengths or negative dist raise ValueError. Degenerate/empty/nonfinite grids are not comprehensively validated by the implementation.
