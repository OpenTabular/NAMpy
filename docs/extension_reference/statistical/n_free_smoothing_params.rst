n_free_smoothing_params
=======================

.. math::

   s_{\mathrm{free}}=\sum_{j=1}^{s}\mathbf1\{\text{fixed\_mask}_j=\mathrm{False}\}

A term can own several penalties, and several terms can share one smoothing coordinate. The number of free smoothing parameters therefore differs from the number of smooth terms and from coefficient dimension. This helper counts coordinates after the compiled penalty mapping.

Supplied fixed strengths are excluded through the fixed mask. With no mask it returns the total coordinate count. The count is bookkeeping: turning automatic selection off holds the current values for a coefficient solve, but does not necessarily mark every coordinate fixed in this mask. Inspect the optimization flag separately.

Import: ``from nampy.gam.fit.selection import n_free_smoothing_params``. These are backend helper APIs; core-model methods remain the usual analysis interface.

Signature
---------

.. code-block:: python

   n_free_smoothing_params(model)

Parameters
----------

``model`` — Type: fitted core ``nampy.gam.GAM``
   Default: ``required``. Use a fitted core model, or ``estimator.gam_`` from a wrapper. Required compiled/fitted state is read from this object; passing a wrapper directly is not supported.

Outputs
-------

``return value`` — Type: int >= 0, shape ()
   Count of entries not marked fixed in ``smoothing_fixed_mask_``; with no mask, count of model smoothing coordinates. A fixed-SP solve can still have entries marked free: ``optimize_smoothing=False`` does not change this bookkeeping count into zero.
