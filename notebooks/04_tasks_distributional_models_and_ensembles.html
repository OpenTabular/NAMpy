Tasks, distributional models, and ensembles

This notebook turns NAMpy’s installed registries into executable capability reports. It discovers task variants at runtime, fits each supported neural architecture under a tiny common budget, evaluates the distribution-family catalog, and demonstrates independent ensembles. A failed fit is recorded rather than silently converted into a checkmark.

1. Registry-driven experimental setup

Architecture support and successful demonstration are different facts. The registry states what an architecture exposes; the sweep records what executed in this environment. Fast mode uses one development batch per estimator so broad interface coverage remains practical. Disable fast mode for meaningful learning curves and comparisons.

def estimator_class(spec, suffix):
    return getattr(models, f"{spec.estimator_prefix}{suffix}", None)

def make_estimator(name, spec, suffix, **extra):
    cls = estimator_class(spec, suffix)
    if cls is None:
        return None
    kwargs = dict(MODEL_KWARGS[name])
    kwargs.update(extra)
    return cls(**kwargs)

def reconstruction_error(estimator, features):
    components = estimator.predict_components(features, center=True)
    link = np.asarray(components.link)
    def aligned(value):
        array = np.asarray(value, dtype=float)
        if link.ndim == 1 and array.shape == (link.shape[0], 1):
            return array[:, 0]
        if link.ndim == 2 and array.shape == (link.shape[0],):
            return array[:, None]
        return array
    reconstruction = aligned(components.intercept)
    for contribution in components.terms.values():
        reconstruction = reconstruction + aligned(contribution)
    if components.offset is not None:
        reconstruction = reconstruction + aligned(components.offset)
    error = float(np.max(np.abs(reconstruction - link)))
    try:
        components.validate_additive_reconstruction(rtol=1e-5, atol=1e-5)
        valid = True
    except ValueError:
        valid = False
    return error, valid

2. Regression across architectures

Every registered regression architecture is fitted on the same rows. The score, runtime, additive reconstruction, and term importance are recorded. Architecture-specific output is added where available. This confirms the installed runtime rather than relying on a copied documentation matrix.

regression_models = {}
regression_rows = []
for name, spec in architectures().items():
    if not spec.supports("regression"):
        continue
    estimator = make_estimator(name, spec, "Regressor")
    started = time.perf_counter()
    try:
        estimator.fit(X, y_reg, **SWEEP_FIT_KWARGS)
        importance = estimator.term_importance(X, center=True)
        error, reconstruction_valid = reconstruction_error(estimator, X)
        row = {
            "architecture": name,
            "status": "Demonstrated",
            "R2": estimator.score(X, y_reg),
            "seconds": time.perf_counter() - started,
            "reconstruction error": error,
            "reconstruction valid": reconstruction_valid,
            "most important term": importance.iloc[0]["term"] if len(importance) else None,
        }
        if hasattr(estimator, "local_term_importance") and spec.supports("local_term_importance"):
            row["special output"] = "local importance"
        elif name == "igann":
            row["special output"] = f"{estimator.n_estimators_} boosting stages"
        else:
            row["special output"] = None
        regression_models[name] = estimator
    except Exception as error:
        row = {"architecture": name, "status": f"Failed: {type(error).__name__}", "error": str(error)}
    regression_rows.append(row)

regression_report = pd.DataFrame(regression_rows)

3. Classification across architectures

Classifier components reconstruct logits (binary) or class-score vectors before the probability transform. Log loss evaluates probability quality, ROC-AUC evaluates ranking for the positive class, accuracy evaluates hard labels, and calibration error compares binned predicted and empirical frequencies. Link-scale terms explain the model score—not an additive decomposition of probability.

def expected_calibration_error(y_true, probability, bins=6):
    edges = np.linspace(0, 1, bins + 1)
    index = np.clip(np.digitize(probability, edges) - 1, 0, bins - 1)
    total = len(y_true)
    return sum(
        np.sum(index == b) / total * abs(np.mean(probability[index == b]) - np.mean(y_true[index == b]))
        for b in range(bins) if np.any(index == b)
    )

6. Independent neural ensembles

NeuralEnsemble clones and fits regressors or classifiers independently. Bootstrapping changes member datasets; random seeds change initialization and data order; n_jobs controls parallel fitting. Predictions are averaged on the response scale, while terms and links are averaged on the additive scale. Persistence is inherited from the member estimators only; the complete ensemble can be serialized with joblib.

6.1 Three different meanings of uncertainty

  • Ensemble disagreement measures variation among fitted neural members under seeds and/or bootstrap samples. It is not automatically a calibrated confidence interval.

  • GAM standard errors arise from an approximate sampling covariance for fitted coefficients, conditional on model assumptions and optionally including smoothing uncertainty.

  • LSS conditional uncertainty is the predicted response distribution for a new outcome given its features. It can be large even if parameter estimates are known precisely.

7. Final capability report

Cells use four states. Demonstrated means this notebook executed the task successfully. Supported but not demonstrated comes from the registry but lacked a successful run. Unavailable means the registry does not expose the capability. Not applicable is reserved for a concept that does not make sense for that architecture.

def task_status(name, capability, report):
    spec = architectures()[name]
    if not spec.supports(capability):
        return "Unavailable"
    match = report.loc[report["architecture"] == name]
    if len(match) and match.iloc[0]["status"] == "Demonstrated":
        return "Demonstrated"
    return "Supported but not demonstrated"

8. Reading the reports responsibly

A successful one-batch fit proves API wiring, output domains, and reconstruction—not predictive quality. A registry capability proves an exposed contract—not that the architecture is the right scientific model. For analysis, disable fast mode, choose metrics before fitting, tune inside cross-validation, use repeated splits, inspect term stability, and compare against simple baselines.
